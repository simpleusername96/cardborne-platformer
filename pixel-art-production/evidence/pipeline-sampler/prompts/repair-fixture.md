# Repair Fixture ImageGen Prompt

Use case: stylized-concept
Asset type: Cardborne game facility sprite, canonical base for a 64x64 logical pixel grid
Input image: the supplied 512x512 image is a 64-by-64 logical-cell construction grid. Use it as the exact cell guide.
Primary request: create one top-down repair fixture for a vehicle action shooter.
Subject: a compact planted facility with a broad deep-gray mechanical base and one unmistakable mint plus-shaped repair core in the center. Four short squared support feet make it look stationary, not collectible. The active gameplay radius and timer must not be drawn.
Camera/composition: strict 90-degree top-down, one object only, centered, symmetric, at least six logical cells of empty margin.
Pixel construction: every occupied logical cell is filled edge-to-edge; large contiguous orthogonal regions; simple boundaries separating base, repair core, and activation part.
Palette: only #596774, #222B35, #75C4B2, #E8EEF0, and the white supplied grid/background.
Constraints: preserve the visible construction grid as guidance; no complete scene, no floor plane, no cast shadow, no universal outline, no gradients, no antialiasing, no dithering, no glow, no texture, no scratches, no tiny panels, no text, no numbers, no logo, no watermark, no extra object. The fixture must not resemble a pickup, enemy, projectile, or wall.
