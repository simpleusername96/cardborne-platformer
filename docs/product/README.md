# Product Documentation

The current executable is the three-stage vehicle run described by
[`vehicle_content_expansion_spec.md`](./vehicle_content_expansion_spec.md).
[`vehicle_stage_one_experimental_spec.md`](./vehicle_stage_one_experimental_spec.md)
is the earlier draft experiment boundary and is not current authority.

[`progression_upgrade_system_spec.md`](./progression_upgrade_system_spec.md) is
the active future boundary for cards, materials, skills/stats, equipment, Forge,
and reward transactions. It does not authorize broad meta-progression work by
itself.

[`isometric_action_rpg_product_brief.md`](./isometric_action_rpg_product_brief.md)
remains lifecycle-marked as an active humanoid-proof specification, but it no
longer describes the main boot path. Superseding that active specification and
the related protected policy requires an explicit owner decision; see
[`../README.md`](../README.md#known-authority-conflict).

Do not infer current runtime behavior from the retained humanoid proof or deleted
platformer implementation. Use the specification whose stated scope matches the
surface being inspected.
