# Product Documentation

The previous platformer PRD was retired during the isometric action RPG pivot.
[`isometric_action_rpg_product_brief.md`](./isometric_action_rpg_product_brief.md)
is the active product contract for the proof build.

[`progression_upgrade_system_spec.md`](./progression_upgrade_system_spec.md) is
the active future boundary for cards, materials, skills/stats, equipment, Forge,
and reward transactions. It does not authorize progression implementation during
the current map/enemy slice.

The active Floor 1 plan implements connected rooms, moving enemies, props,
Slime King, and audio settings phase by phase. Do not infer runtime behavior from
the deleted platformer implementation; only the reviewed boundary concepts named
by the current specs may be re-derived.
