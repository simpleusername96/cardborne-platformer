# Product Docs

Use these documents in this order when they disagree:

1. `FIRST_COMPLETE_RUN_SCOPE_DELTA.md` is the canonical scope and clause-level
   override for the first complete Cardborne run.
2. `2d_platform_action_card_game_prd.md` remains the active baseline for product
   identity, movement, cards, combat readability, stage cadence, and boss behavior
   where the scope delta does not override it.
3. `FIRST_SLICE_EXPANSION.md` remains active RPG-lite detail for XP, coins,
   materials, equipment, and encounters where compatible with the scope delta.
4. `.agent/execplans/2026-07-12-actual-game-production-roadmap.md` defines active
   execution order and validation gates; it is not product-spec authority.

Testbed plans and handoffs are historical or diagnostic evidence unless an active
product or design specification links them for a narrowly stated purpose.
