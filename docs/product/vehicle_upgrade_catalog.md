# 차량 업그레이드 카탈로그

## 목적과 현재 규모

이 문서는 8개 보스 사이클 런에서 실제로 등장하는 카드, 레벨별 효과, 보조 무기 슬롯,
발동무기, 조건부 피해 계산과 카드 제안 규칙을 정의한다. 현재 카탈로그는 **27장,
명목상 91레벨 상태**다. 피해 속성은 하나를 고르고 냉기는 유일한 유틸리티
속성이다. 자동 무기는
여섯 종류 중 최대 세 종류, 발동무기는 네 종류 중 하나만 고른다. 한 런에서
합법적으로 선택할 수 있는 총 레벨은 선택 경로에 따라 **63~65회**다.

Dash만 기본 액션이다. 추적 미사일을 포함한 모든 자동 무기와 EMP를 포함한 모든
발동무기는 카드로 처음 획득한다. 발동무기는 피해를 주지 않으며 무기별 범위·제어
지속시간 또는 강도·재사용 성장은 해당 카드의
레벨에 포함되며 공용 무기 강화 카드는 없다. 모든 카드는 런 한정이다.

## 피해 합성 규칙

1. 대시 강화와 저체력 피해 보너스를 더한다.
2. 합산 조건부 보너스는 최대 +100%로 제한한다.
3. 치명타가 발생하면 위 결과에 2배를 곱한다.
4. 치명타는 직접 피해에만 적용한다. 지속 피해는 치명타를 내지 않는다.

이 순서가 런타임, 카드 미리보기와 전투 보고서의 공통 계약이다.

## 보상과 제안 규칙

각 보상은 다음 순서로 처리한다.

1. 호환되며 최대 레벨이 아닌 카드를 모은다.
2. 자동 무기 세 종류를 이미 획득했다면 다른 자동 무기의 첫 획득을 막는다.
3. 각 속성 슬롯에서 하나를 획득했다면 같은 슬롯의 다른 속성을 막는다.
4. 발동무기 종류 하나를 획득했다면 다른 발동무기 종류를 막는다.
5. 발동무기가 없으면 발동무기 한 장을 예약하고, 자동 무기가 없으면 자동 무기 한 장을
   예약한다. 둘 다 없으면 각각 한 장을 예약한다. 해당 종류를 획득하면 그 예약만 끝낸다.
6. 런 시드, 보스 사이클, 보상 출처와 일련번호로 결정론적으로 섞는다.
7. 첫 레벨업도 위 예약을 적용하고 남은 자리를 그 밖의 합법 카드로 채운다.
8. **보스 사이클 3부터** 미완성 공격 카드가 하나라도 있으면 제안 세 장 중 최소 한 장을
   공격 카드로 보장한다.
9. 가능한 한 서로 다른 분류를 먼저 고르고, 같은 합법 풀에서 남은 자리를 채운다.
10. 합법 ID가 3개 이상이면 서로 다른 카드 세 장을 고정 제안한다.
11. 합법 ID가 3개 미만이면 보상 거래를 자동 종료하며 사이클 완료를 막지 않는다.
12. 미제안·오래된·중복 제출은 빌드를 바꾸지 않고 거부한다.

공격 카드란 실제 피해를 늘리거나 새 피해원을 추가하는 주무기·보조무기·피해
속성·전투 조건·발동무기 카드를 뜻한다. 냉기와 재사용 감소 카드는 이 보장
집합에 포함하지 않는다. 재추첨, 건너뛰기, 거절, 가짜 대체 카드는 없다.

## 카드 표시 계약

- 업그레이드 화면은 왼쪽 current-build summary와 오른쪽 세 개의 선택 row를 사용한다.
  summary의 슬롯 수는 표시 계약이며 새로운 gameplay 장착 제한이 아니다.
- current-build summary는 catalog 순서의 여섯 section과 고정 capacity
  `2/3/2/1/5/7`을 사용하고 section별 최대 4열로 표시한다. 각 section에서 획득 카드는
  최초 획득 순서대로 왼쪽부터 빈틈없이 채우며, 같은 카드의 레벨 상승은 새 cell을 쓰지
  않는다. 빈 cell은 모든 채워진 cell 뒤에만 온다. Activated는 한 칸이며 획득 전에는
  비어 있고, 획득 뒤에는 선택한 발동무기만 표시한다.
- 각 선택 row는 왼쪽 의미 이미지 하나, 중앙의 분류·제목·실제 수치 변화 1~2개·최대
  한 줄 설명, 오른쪽의 `NEW` 또는 `레벨 N → M`만 표시한다.
- 수치는 `피해 4 → 6   범위 72 → 84`처럼 label과 변화값을 inline phrase로 묶는다.
  label과 값을 좌우 끝으로 벌리거나 별도 표 column으로 나누지 않는다.
- summary의 채워진 슬롯은 hover/focus/click에서 제목·현재 레벨·현재 수치·한 줄
  설명을 popover로 보여준다. 빈 슬롯은 focus를 받지 않는다.
- `unlock`은 없던 동작의 첫 획득, `enhance`는 보유 동작의 강화다. 자동·발동무기
  첫 카드는 현재 입력 안내를 설명에 붙인다. 자동 무기는 자동 사용, 발동무기는 현재
  Active 바인딩으로 사용함을 알리며 후속 레벨에서는 이 안내를 반복하지 않는다.
- UI는 수치를 다시 계산하지 않고 gameplay owner가 만든 frozen snapshot을 쓴다.
- 후방 기뢰 설명에는 “이동하며 뒤에 자동 설치”를 명시한다.
- 대시 잔류장 설명에는 “대시 전체 경로”를 명시한다.
- 한국어·영어 제목, 설명, 수치 라벨은 항상 함께 완결되어야 한다.

## 완료 조건

- 리소스가 정확히 27장이고 최대 레벨 합계가 91다.
- 분류별 카드 수가 주무기 2, 자동 무기 6, 속성 3, 발동무기 4, 차체 5,
  전투 조건 7이다.
- 합법적 최대 선택 횟수가 모든 슬롯·속성·발동무기 경로에서 63~65 범위다.
- 자동 무기는 여섯 종류 중 최대 세 종류다.
- 스테이지 3 이후 미완성 공격 카드가 있으면 매 제안에 최소 한 장이 포함된다.
- 모든 카드 레벨의 한국어·영어 설명과 표시 수치가 실제 gameplay 수치와 일치한다.
- 가장 긴 카드 조합이 960×540, 1280×720, 1920×1080에서 잘리지 않는다.
- 업그레이드 시스템, 조건부 피해, 보조 무기, 카드 UI 집중 검증이 통과한다.
- 빈 빌드는 정확히 17개의 비어 있는 cell을 보이고, 획득한 업그레이드만 이미지가
  채워지고 focus를 받으며, 합법적인 최대 고유 획득 경로도 17개 표시 capacity 안에 든다.
