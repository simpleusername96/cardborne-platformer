# 차량 업그레이드 카탈로그

## 목적과 현재 규모

이 문서는 5스테이지 런에서 실제로 등장하는 카드, 레벨별 효과, 보조 무기 슬롯,
발동무기, 조건부 피해 계산과 카드 제안 규칙을 정의한다. 현재 카탈로그는 **28장,
명목상 92레벨 상태**다. 피해 속성과 보조 속성은 각각 하나를 고르고, 선택형 보조
무기는 다섯 종류 중 두 종류, 발동무기는 한 종류만 고른다. 한 런에서 합법적으로
선택할 수 있는 총 레벨은 선택 경로에 따라 **65~67회**다.

Dash, 추적 미사일, EMP는 기본 액션이다. 발동무기 카드를 고르면 EMP를 해당
무기로 교체한다. 보조무기와 발동무기에는 각각 공용 재사용·피해 강화 카드가 있다.
모든 카드는 런 한정이고 영구 저장 데이터는 만들지 않는다.

## 분류와 슬롯

| 분류 ID | 한국어 / English | 카드 수 | 역할 |
| --- | --- | ---: | --- |
| `primary` | 주무기 개조 / Primary Weapon Mods | 2 | 기본 탄환의 수와 관통 규칙 |
| `secondary` | 보조 무기 체계 / Secondary Weapon Systems | 8 | 기본 추적 미사일, 자율 보조 무기와 공용 강화 |
| `element` | 공격 속성 / Attack Attributes | 4 | 피해 속성 하나와 보조 속성 하나 |
| `activated` | 발동무기 / Active Weapons | 5 | EMP를 교체하는 무기 하나와 공용 강화 |
| `chassis` | 차체 및 지원 / Chassis & Support | 5 | 이동·수거·내구·회복·실드 |
| `combat` | 전투 조건 / Combat Conditions | 4 | 치명타·대시·저체력 화력 |

- 추적 미사일은 `built_in`이고 선택 슬롯을 쓰지 않는다.
- 전기장, 회전 날개, 후방 기뢰, 자동 레이저, 원거리 전격포는 `optional`이다.
- 선택형 보조 무기는 다섯 종류 중 최대 두 종류만 처음 획득할 수 있다. 슬롯이
  찬 뒤에도 이미 획득한 무기의 다음 레벨은 제안할 수 있다.
- 따라서 동시에 활성화되는 보조 무기는 기본 추적 미사일을 포함해 최대 세 종류다.

## 피해 합성 규칙

1. 대시 강화와 저체력 피해 보너스를 더한다.
2. 합산 조건부 보너스는 최대 +100%로 제한한다.
3. 치명타가 발생하면 위 결과에 2배를 곱한다.
4. 치명타는 직접 피해에만 적용한다. 지속 피해는 치명타를 내지 않는다.

이 순서가 런타임, 카드 미리보기와 전투 보고서의 공통 계약이다.

## 보상과 제안 규칙

각 보상은 다음 순서로 처리한다.

1. 호환되며 최대 레벨이 아닌 카드를 모은다.
2. 선택 보조 무기 두 종류를 이미 획득했다면 다른 보조 무기의 첫 획득을 막는다.
3. 각 속성 슬롯에서 하나를 획득했다면 같은 슬롯의 다른 속성을 막는다.
4. 발동무기 종류 하나를 획득했다면 다른 발동무기 종류를 막는다.
5. 런 시드, 스테이지, 보상 출처와 일련번호로 결정론적으로 섞는다.
6. **스테이지 3부터** 미완성 공격 카드가 하나라도 있으면 제안 세 장 중 최소 한 장을
   공격 카드로 보장한다.
7. 가능한 한 서로 다른 분류를 먼저 고르고, 같은 합법 풀에서 남은 자리를 채운다.
8. 합법 ID가 3개 이상이면 서로 다른 카드 세 장을 고정 제안한다.
9. 합법 ID가 3개 미만이면 보상 거래를 자동 종료하며 스테이지 완료를 막지 않는다.
10. 미제안·오래된·중복 제출은 빌드를 바꾸지 않고 거부한다.

공격 카드란 실제 피해를 늘리거나 새 피해원을 추가하는 주무기·보조무기·피해
속성·전투 조건·발동무기 카드를 뜻한다. 냉기·감전과 재사용 감소 카드는 이 보장
집합에 포함하지 않는다. 재추첨, 건너뛰기, 거절, 가짜 대체 카드는 없다.

## 카드 표시 계약

- 업그레이드 화면은 왼쪽 current-build summary와 오른쪽 세 개의 선택 row를 사용한다.
  summary의 슬롯 수는 표시 계약이며 새로운 gameplay 장착 제한이 아니다.
- 각 선택 row는 왼쪽 의미 이미지 하나, 중앙의 분류·제목·실제 수치 변화 1~2개·최대
  한 줄 설명, 오른쪽의 `NEW` 또는 `레벨 N → M`만 표시한다.
- 수치는 `피해 4 → 6   범위 72 → 84`처럼 label과 변화값을 inline phrase로 묶는다.
  label과 값을 좌우 끝으로 벌리거나 별도 표 column으로 나누지 않는다.
- summary의 채워진 슬롯은 hover/focus/click에서 제목·현재 레벨·현재 수치·한 줄
  설명을 popover로 보여준다. 빈 슬롯은 focus를 받지 않는다.
- `unlock`은 없던 동작의 첫 획득, `enhance`는 보유 동작의 강화다. 기본 추적
  미사일의 첫 카드는 `enhance`다.
- UI는 수치를 다시 계산하지 않고 gameplay owner가 만든 frozen snapshot을 쓴다.
- 후방 기뢰 설명에는 “이동하며 뒤에 자동 설치”를 명시한다.
- 대시 잔류장 설명에는 “대시 전체 경로”를 명시한다.
- 한국어·영어 제목, 설명, 수치 라벨은 항상 함께 완결되어야 한다.

- 분류별 카드 수가 주무기 2, 보조 무기 8, 속성 4, 발동무기 5, 차체 5,
  전투 조건 4다.
- 합법적 최대 선택 횟수가 모든 슬롯·속성·발동무기 경로에서 65~67 범위다.
- 선택형 보조 무기는 다섯 종류 중 최대 두 종류다.
- 스테이지 3 이후 미완성 공격 카드가 있으면 매 제안에 최소 한 장이 포함된다.
- 모든 카드 레벨의 한국어·영어 설명과 표시 수치가 실제 gameplay 수치와 일치한다.
- 가장 긴 카드 조합이 960×540, 1280×720, 1920×1080에서 잘리지 않는다.
- 업그레이드 시스템, 조건부 피해, 보조 무기, 카드 UI 집중 검증이 통과한다.
