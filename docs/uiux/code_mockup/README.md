# First Slice UI Code Mockup

This folder contains a standalone HTML/CSS/JS mockup for the first-slice screen flow.

Open `index.html` in a browser. No build step or dev server is required.

Implemented prototype areas:

- Start, settings, character select, normal stage, card reward, rest/shop, forge/enchant, boss, and run clear screens.
- Fixed run sequence with seed-based stage landscape preview.
- Forge/enchant equipment preview with item-specific stat roll probabilities.
- Screen-level inspector for implementation elements and system responsibilities.

This is not runtime Godot UI. It is code-based UX scaffolding for reviewing what should be implemented before `.tscn` scenes and gameplay scripts are created.
