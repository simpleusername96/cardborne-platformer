Already decided

Movement and combat

  • The map stays open. No maze and no dead end.
  • Standing heal and attack pads are removed.
  • Fixed enemy objects become world objects that can hurt both sides.
  • A normal enemy attacks only after its body is visible.
  • Each stage uses a small set of enemy jobs.

Rewards and builds

  • If a world danger kills an enemy, it gives normal progress and experience points.
  • Build groups have clear maximum counts.
  • Upgrades must change play, not add weak number text.
  • Later bosses get more rules and stronger mixes.
  • Only a few bosses may use outside objects.
