This is a design direction. It is not the current game.

The current product spec and code still describe the game that runs now. They must be updated before the new rules are implemented.

Work in this order

Later art work will fail again if the gameplay rule under it is still moving.

  1. Align the product spec. Record G1, G2, open movement, no dead ends, neutral devices, attack visibility, and the new boss rule.
  2. Prove one playable stage. Test cover, neutral hazards, moving boxes, a small enemy roster, and the new attack gate with simple current assets.
  3. Prove the build loop. Enforce G2 limits and replace weak number-only cards with choices that change play.
  4. Build boss growth. Give each boss one idea, one weakness, and new phase rules before raising health.
  5. Replace map and effect art. Review real-size PNG candidates only after gameplay size, repeat, state, and owner rules are stable.

Who decides what

Locked by you

Core rules

  • G1: a neutral terrain or device kill gives stage progress and XP.
  • G2: hard caps for main gun, element, optional weapons, dash, EMP, and defense.
  • Fast movement and no dead ends.
  • Cover gives short safety.
  • Fixed hostiles become neutral.
  • No waiting support-pad loop.
  • No SVG/ImageMagick asset authoring.
Codex can decide

Safe first values

  • Seed and socket rules.
  • First timer and count values.
  • Stage enemy mixes inside the cap.
  • Neutral device placement.
  • Effect phase names and UI spacing.
  • Boss pattern combinations.
Ask you later

Visible product choices

  • Final map asset direction.
  • Final effect family direction.
  • Any exception to G2.
  • Any exception to the “only 1–2 bosses use external objectives” rule.
  • Large changes to the five-stage run.

How to read evidence

“Current” means the code, spec, production manifest, or runtime capture supports the claim. “Locked” means the user gave the rule. “Approved direction” means it should guide the redesign but is not live yet. “Open” means a visible product choice is still needed.

Old generated sheets remain rejected. They may show layout problems, but they are not asset candidates.
