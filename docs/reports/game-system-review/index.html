2026-08-07 분석 완료

이펙트와 업그레이드를 필요한 행동만 남기는 구조로 정리했습니다.

현재 이펙트 카탈로그 4개, 업그레이드 19개와 39개 레벨 상태를 실제 런타임·카드 UI·검증기 기준으로 정리했습니다.

이펙트 생성 경로 정리는 구현되었습니다. 공격 범위·투사체·피격·지속 상태는 원래 상태 소유자가 직접 표시하며, 성능은 별도 최종 측정 전까지 통과로 간주하지 않습니다.

피드백에서 확정된 기준

무엇을 기준으로 고치는가

일관성

같은 결과는 같은 표현

서로 다른 결과는 구분하고, 같은 효과라도 플레이어와 적의 소유권은 즉시 읽혀야 합니다.

경계

중복 경고를 만들지 않음

화면 안 공격은 실제 탄환과 정확한 피해 범위로 읽습니다. 화면 밖에서 들어오는 투사체만 짧은 경로나 레이더로 보이며, 일반 적 위치는 미니맵만 표시합니다.

업그레이드

행동과 전후 차이를 먼저 표시

카드는 이름·분류·레벨·현재→다음 수치·설명·새 행동을 전달하고, 선택은 계속 필수입니다.

소유권

카드와 월드 이펙트를 분리

업그레이드는 행동·강도·빈도를, 월드 표현은 전투 중 의미를 소유합니다. 카드 그림으로 전투 피드백을 대신하지 않습니다.

구현 완료

이펙트: 버퍼에는 실제로 그리는 네 종류만 유지

새 래스터 에셋은 만들지 않습니다. EMP 한 장과 현재 코드 기반 도형·상태 표현 안에서 해결합니다.

4개

이벤트 저장 경계

대시 잔상, EMP 충전 범위, EMP 방출, 보스 감소 피해 숫자만 96칸 재사용 저장소에 들어갑니다. 나머지 이벤트 ID와 생성 경로는 삭제했습니다.

직접 상태

피격과 방어막

선체 피격은 기존 액터 점멸과 피해 상태를 사용합니다. 방어막 흡수는 별도 이벤트 없이 기존 링을 0.16초 밝히며 선체 흔들림이나 무적 시간을 만들지 않습니다.

공통 정책

공격 범위와 화면 밖 경고

원형 범위는 외곽 링 하나, 돌진·빔은 실제 경계만 남겼습니다. 화면 안 투사체 경로와 장식 표식은 삭제하고, 화면 밖에서 진입하는 공격만 짧은 경로나 레이더 중 하나로 표시합니다.

구현 완료

업그레이드: 19장으로 축소하고 여섯 분류를 분리

주무기·보조 무기·원소·대시·EMP·차체로 분류하고, Pickup Magnet를 포함한 역할이 분명한 카드만 유지합니다.

14장

행동 카드는 획득과 강화를 구분

행동 카드 14장은 첫 획득에 ‘새 행동’, 이후 레벨에 ‘행동 강화’를 표시합니다. 5개 수치 카드는 실제 현재→다음 값을 표시합니다.

거래 계약

동결된 서로 다른 세 장

모든 레벨업과 보스 보상은 합법적인 카드 세 장을 동결합니다. 런타임은 그 제안에 포함된 ID 한 개만 한 번 적용하며, 세 장을 만들 수 없으면 모달을 열지 않고 명시적으로 실패합니다.

분리

분류·변화·슬롯의 세 축

category는 빌드 분류만, change kind는 수치·해금·강화를, secondary slot kind는 내장·선택 슬롯을 표현합니다. 여러 의미를 섞던 family와 오래된 대체·제외 필드는 제거했습니다.

구현 순서

네 단계로 고치고 각 단계에서 되돌림 지점을 만듭니다

  1. 완료: 최소 이펙트 계약 검증

    카탈로그·생성기·보조 무기·렌더러 검증이 네 이벤트 외의 장식 데이터가 다시 들어오는 것을 막습니다.

  2. 완료: 이펙트 경계와 방어막 피드백

    실제 렌더 대상만 저장하고 방어막 피격은 기존 링 상태에서 직접 처리합니다.

  3. 완료: 공격 큐와 레이더 중복 제거

    정확한 피해 경계와 화면 밖 진입 위험만 남기고, 일반 적 위치·보이는 탄환 경로·장식 표식을 제거했습니다.

  4. 완료: 업그레이드 표시와 거래 계약

    19장 카탈로그, 여섯 분류, 행동 카드 레이아웃, 세 장 불변식, 현재 제안에 속한 카드만 적용하는 경계를 함께 고쳤습니다.

  5. 실전 압박 QA와 Web 확인

    다섯 스테이지 대표 장면과 주요 빌드에서 소유권·경계·텍스트 넘침·행동 발동을 확인하고 Web 내보내기와 빌드 실행을 검증합니다. 성능 최종 판정은 별도 활성 계획에서 마칩니다.
