요약 이펙트 업그레이드 실행 순서

2026-08-07 분석 완료

다음 작업은 새 그림 추가가 아니라, 전투 의미와 업그레이드 선택의 빈틈을 닫는 일입니다.

기존 피드백, 현재 39개 시각 이벤트, 41개 업그레이드와 83개 레벨 상태, 실제 렌더러·카드 UI·검증기를 함께 대조했습니다.

이 문서는 현재 상태와 확정한 수정 방향만 보여 줍니다. 상세 구현 계약은 아래 실행계획이 소유하며, 성능은 별도 최종 측정 전까지 통과로 간주하지 않습니다.

피드백에서 확정된 기준

무엇을 기준으로 고치는가

일관성

같은 결과는 같은 표현

서로 다른 결과는 구분하고, 같은 효과라도 플레이어와 적의 소유권은 즉시 읽혀야 합니다.

경계

범용 링을 남발하지 않음

실시간 공격 범위는 실제 판정과 맞추고, 경고는 보스·화면 밖 장치·대형 중립 사건에 한정합니다.

업그레이드

행동과 전후 차이를 먼저 표시

카드는 이름·계열·레벨·현재→다음 수치·설명·새 행동을 전달하고, 선택은 계속 필수입니다.

소유권

카드와 월드 이펙트를 분리

업그레이드는 행동·강도·빈도를, 월드 표현은 전투 중 의미를 소유합니다. 카드 그림으로 전투 피드백을 대신하지 않습니다.

우선순위 1

이펙트: 보이지 않는 이벤트와 빠진 상태 피드백 정리

새 래스터 에셋은 만들지 않습니다. EMP 한 장과 현재 코드 기반 도형·상태 표현 안에서 해결합니다.

높음

이벤트 저장 경계

렌더러는 direct feedback·suppressed·HUD-only 모드 34개를 그리지 않지만, 발생 시 96칸 효과 저장소를 사용할 수 있습니다. 실제 렌더 대상만 저장하고 나머지는 상태·HUD·오디오 소유자를 명시합니다.

높음

방어막 피격

피해가 방어막에서 끝나면 별도 피격 펄스와 소리가 없습니다. 기존 방어막 윤곽을 짧게 밝히는 코드 기반 펄스를 추가하되 선체 흔들림·무적 시간은 만들지 않습니다.

높음

표식과 절단 상태

현재 표식·절단 표시는 repair tender 적에게만 도달하는 분기 안에 있고 둘 다 링을 사용합니다. 모든 대상에 표시하고, 표식은 황색 네 모서리 브래킷, 절단은 민트색 양측 분리 바로 구분합니다.

우선순위 2

업그레이드: 행동 카드와 세 장 선택 계약 보강

41개 카드와 현재 성장 구조는 유지합니다. 별도 성장 시스템이나 새 카드 수를 추가하지 않습니다.

가장 먼저

28개 행동 카드의 ‘새 행동’ 표시

행동 카드 28개는 수치 행이 없고 요약과 설명 키가 같아 전용 행동 행이 비어 있습니다. 기존 문장을 중복하지 않고 비교 영역에 한국어·영어 ‘새 행동’ 라벨과 행동 설명을 표시합니다.

계약 보강

항상 서로 다른 세 장

현재 제안기는 가능한 만큼 반환하므로 고갈 직전·제한 태그 조합에서 세 장을 보장하지 않습니다. 도달 가능한 모든 보상 상태를 검사하고, 세 장이 아니면 모달을 열지 않는 명시적 오류 경계로 실패시킵니다.

정리

카탈로그와 적용 경계

중복 ID 덮어쓰기, 허용되지 않은 수치 연산·슬롯 종류, 제안되지 않은 카드 적용을 검증합니다. 모든 카드가 명시적 artwork ID를 가지므로 오래된 대체 매핑과 미사용 exclusion 필드는 제거합니다.

구현 순서

네 단계로 고치고 각 단계에서 되돌림 지점을 만듭니다

  1. 계약 검증부터 추가

    고아 이벤트, 저장 가능 모드, 28개 행동 카드, 세 장 제안, 제안 외 적용을 실패시키는 검증을 먼저 만듭니다.

  2. 이펙트 경계와 상태 피드백 수정

    렌더 대상만 효과 저장소에 넣고, 방어막·표식·절단 피드백을 기존 코드 기반 렌더러 안에서 구현합니다.

  3. 업그레이드 표시와 거래 계약 수정

    행동 카드 레이아웃, 세 장 불변식, 카탈로그 스키마, 현재 제안에 속한 카드만 적용하는 경계를 함께 고칩니다.

  4. 실전 압박 QA와 Web 확인

    다섯 스테이지 대표 장면과 주요 빌드에서 소유권·경계·텍스트 넘침·행동 발동을 확인하고 Web 내보내기와 빌드 실행을 검증합니다. 성능 최종 판정은 별도 활성 계획에서 마칩니다.
