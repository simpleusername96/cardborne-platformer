Upgrade review

Upgrades should make a clear build.

The offer screen owns the choice and the behavior. The Effects page owns the live runtime look.

Current factsG1 and G2 lockedApproved directionNot implemented
Approved direction, not implemented.

The current catalog enforces only the two optional-weapon slots. G1 needs a formal spec rule for neutral-device kills. The full G2 caps still need runtime enforcement before the UI can show them as truth.

Three priorities

  1. State the behavior: make each card say what changes in play.
  2. Enforce the build: apply every G2 cap in data, then show it on the card.
  3. Separate the look: card art explains a choice; the Effects page owns the live result.

Locked rules

G1 · shared rule

Builds do not own scoring

The overview owns G1. Upgrade data must not change whether a neutral kill gives stage progress and XP.

G2 · locked

Build caps

  • Main gun form: 1
  • Element root: 1
  • Optional weapons: 2
  • Seeker: built in; no slot
  • Dash effect: 1 · EMP effect: 1 · Defense: 1
  • Selected module: max level 3; it may stop earlier

Upgrade UI guidance

Card counter

Show Main 1 / 1, Element 1 / 1, and Optional 0 / 2. Show level as Lv. 2 → 3.

Choice first

Keep the title, comparison, behavior sentence, and cap visible. Do not make the player infer behavior from art.

One art role

Use one related image below the card title. It is card art, not a live effect preview.

Upgrade data chooses the behavior. Effects & readability owns how that behavior looks during play.

Keep-or-cut test

Codex can rewrite or remove a card without asking for every line. A card stays only when most answers are yes.

Player test

  1. Can the player feel it soon?
  2. Does it matter in normal combat?
  3. Does it change aim, movement, timing, or target choice?
  4. Does it avoid copying an item, pad, or another card?

First behavior lanes

Main-gun form, one element root, Seeker target rule, dash form, EMP form, optional weapon, and defense. Each lane needs a clear job.

Delegated and open choices

Codex can decide

Upgrade data owns behavior, level, cap checks, and distinct behavior copy. UI only shows that truth. Weak number-only cards can be rewritten inside the locked lanes.

Ask you only for a rule change

A new weapon family, an exception to G2, or a major change to the five-stage build loop needs your approval.
