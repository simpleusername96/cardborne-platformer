Topic 5 of 5 · Bosses

Bosses need new rules, not only more health.

Each phase should teach, add, then remix a clear fight idea. Normal damage must stay useful.

Current system checked Approved direction Not implemented
Authority warning: this page is direction, not a game change.

The product spec still requires the current boss objectives. Do not remove or change them from this page alone. Any implementation needs a scoped plan and product approval.

Priority: make each boss easy to read and fair to solve.

  1. Teach. Phase 1 shows one main idea and its safe answer.
  2. Add. Phase 2 adds one new rule. It does not only run faster.
  3. Remix. Phase 3 combines the learned rules with a clear damage chance.

Exact values

Boss UI and warning rules

Always show

  • Boss health and phase change.
  • What can take damage now.
  • Where the next danger will land or pass.
  • A clear cue when a weakness opens or closes.

Use with care

  • Long or offscreen attacks are allowed only when needed for the boss idea.
  • Show the danger area before it can hurt the player.
  • Keep the source, path, and safe exit easy to find.
  • Do not make the player search offscreen for required damage targets.

One-boss formula

1

Core idea

Write one clear sentence.

2

3 patterns

Teach three fair player answers.

3

Weakness

Give a position, timing, or target choice.

4

New phase rule

Add a rule; do not only reorder.

5

Final remix

Combine learned rules and keep a fair opening.

Options

Weakness ideas

Close bonus, side opening, breakable weapon, interruptible charge, hazard use, or selected external nodes.

Show three example pattern mixes

Fast close-range boss

Charge + aimed fan + moving hazard lane. Close attacks get a bonus, but the boss moves away often.

Breakable-weapon boss

Rotating turret + sweeping beam + ground marker. Break one weapon to remove the hardest pattern for this build.

Arena-control boss

Ring burst + limited summons + arena squeeze. Use a neutral hazard to make a short damage opening.
