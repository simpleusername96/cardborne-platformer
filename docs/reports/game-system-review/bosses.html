Bosses

Bosses need more rules, not only more health.

Each boss needs a clear idea, fair openings, and stronger pattern mixes later in the run.

1 · Problem

Weak and repeated

  • Patterns are too simple.
  • Bosses are too weak.
  • “Find and break outside objects” repeats too often.

2 · Fix

Teach, add, combine

  • Phase 1 teaches the main rule.
  • Phase 2 adds a new answer.
  • Phase 3 combines learned rules with a fair opening.

3 · Decided

Boss rules

  • Outside objects are used by only one or two bosses.
  • Normal damage is always useful.
  • A boss may reward close range but move away fast.
  • Later bosses use more and stronger patterns.

Why the fight feels flat

The boss, outside objects, and attack path do not create enough different decisions over time.

I will handle this

One simple boss formula

  1. One clear idea
    Example: close attacks deal more damage, but the boss escapes often.
  2. Three fair patterns
    Each pattern has a warning, an answer, and a safe opening.
  3. One new rule per phase
    Do not use speed alone as the phase change.
  4. A final mix
    Combine learned patterns without removing every safe exit.
