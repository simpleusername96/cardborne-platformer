# 기체 업그레이드 아이디어 카탈로그

## Purpose

현재 5스테이지 런에서 선택지가 너무 일찍 소진되고, 4스테이지 후반부터 적 체력
증가를 플레이어 화력이 따라가지 못하는 문제를 해결하기 위한 아이디어 모음이다.
바로 적용할 작은 수치 확장과, 이후 검토할 보편적·실험적 업그레이드를 분리한다.

이 문서는 아이디어와 근거를 보존하는 조사 문서다. 실제 적용이 확정된 동작은
`docs/product/vehicle_upgrade_catalog.md`와 제품 명세에 반영되어야 한다.

## Findings

### 1. 현재 카탈로그와 막히는 지점

현재 카드는 13종이고 명목상 최대 레벨 합계는 36이다. 하지만 한 런에서는 원소를
하나만 고를 수 있고 선택 보조 무기도 3개 중 2개만 장착할 수 있어 실제 도달 가능한
최대 선택 횟수는 27이다.

| 분류 | 카드 | 현재 최대 레벨 | 공격력에 직접 기여 |
| --- | --- | ---: | --- |
| 주무기 | 확산 총구 | 2 | 예 |
| 주무기 | 관통 탄환 | 3 | 예, 다중 표적 |
| 기본 보조 | 추적 미사일 | 2 | 예 |
| 선택 보조 | 전기장 | 3 | 예 |
| 선택 보조 | 회전 날개 | 3 | 예 |
| 선택 보조 | 후방 기뢰 | 3 | 예 |
| 원소 | 열 폭발 | 3 | 예 |
| 원소 | 생체 독소 | 3 | 예 |
| 원소 | 냉각 감속 | 3 | 직접 피해 없음 |
| 차체 | 속도, 체력, 흡혈, 수거 범위 | 2~3 | 간접 기여 |

4스테이지 일반 적 체력은 기본 역할 체력에 클래스, 스테이지, 후반 압력, 전체 일반
적 배율이 곱해진다. 표준/군집 적은 기본 체력의 약 7.00배, 우선/고정 적은 약
6.25배가 된다. 기본 주무기는 이론상 150 DPS지만 벽, 빗나감, 표적 전환, 방어막의
주무기 피해 55% 감소가 추가된다. “적이 많아서 어려움”보다 “처치 시간이 길어져
새 적이 쌓이고, 플레이어는 공격 대신 도주만 함”이 후반 지연의 핵심 구조다.

레벨만 늘려도 선택 가능한 시간이 길어지고 최고 화력이 오른다. 그러나 제안 카드가
무작위라 공격 카드를 받지 못하면 같은 문제가 남는다. 따라서 작은 첫 조치는
`공격 카드 +1레벨`과 `후반 공격 선택지 최소 1장`을 함께 다루는 편이 안전하다.

### 2. 바로 적용할 공격 레벨 확장안

투사체·날개·기뢰 개수를 더 늘리면 현재 성능 문제를 악화시킬 수 있다. 새 레벨은
개체 수와 판정 빈도를 그대로 두고, 기존 공격 하나의 위력을 높이는 방향으로 잡는다.

| 카드 | 새 최대 | 새 최종 상태 | 현재 최종 대비 의도 |
| --- | ---: | --- | --- |
| 확산 총구 | 3 | 3발 유지, 측면탄 각각 40%, 총 180% | 총 일제 피해 `165% → 180%` |
| 관통 탄환 | 4 | 추가 관통 4회 | 탄 수 증가 없이 밀집 적 처리 향상 |
| 추적 미사일 | 3 | 3발 유지, 발당 피해 38 | 동시 투사체를 늘리지 않고 약 18.8% 강화 |
| 전기장 | 4 | 반지름 160 유지, 22 DPS | 조회 범위·틱 간격 유지, DPS 강화 |
| 회전 날개 | 4 | 날개 4개 유지, 접촉 피해 28 | 월드 인스턴스 수 유지, 타격 강화 |
| 후방 기뢰 | 4 | 최대 5개·2.4초·반지름 120 유지, 피해 88 | 기뢰 수명·판정 수 유지, 피해 강화 |
| 열 폭발 | 4 | 반지름 96 유지, 추가 피해 11 | 광역 후보 수를 늘리지 않고 피해 강화 |
| 생체 독소 | 4 | 지속 7초 유지, 중첩당 5.5 DPS | 상태 수명은 늘리지 않고 피해 강화 |

이렇게 하면 카탈로그 명목 레벨 합계는 36에서 44로, 한 런에서 실제로 선택 가능한
상한은 27에서 33으로 늘어난다. 선택 제한 때문에 8개 새 레벨을 한 런에서 모두
얻지는 못한다. 실제 빌드에서는 주무기 2개, 기본 보조 1개, 선택 보조 2개, 선택한
원소 1개의 새 레벨까지 총 6회가 추가된다.

3~5스테이지 보상 제안에는 현재 빌드와 호환되는 미완성 공격 카드가 하나라도 있으면
최소 1장을 포함한다. 카드 3장, 중복 금지, 카테고리 다양성, 선택 보조 2개 제한,
원소 1개 제한은 유지한다. 이 규칙은 특정 카드를 강제로 주는 것이 아니라 후반에
방어·편의 카드만 나와 화력 성장이 막히는 경우를 제거한다.

### 3. 범용 수치 성장 — 가장 익숙한 아이디어

| 아이디어 | 효과 | Cardborne 적용 예 | 주의점 |
| --- | --- | --- | --- |
| 기본 피해 | 모든 주무기 피해 증가 | `+12% → +24% → +36%` | 모든 빌드의 필수 카드가 되기 쉬움 |
| 공격 속도 | 발사 간격 감소 | 기본탄 간격을 단계별로 6~8% 감소 | 투사체·충돌·효과 부하 증가 |
| 치명타 | 확률로 큰 피해 | 낮은 확률, 큰 숫자와 전용 피드백 | 짧은 전투에서 운 편차가 큼 |
| 방어구 관통 | 방어막/장갑 상대로 유리 | 방어막의 주무기 감소율 일부 무시 | 특정 적만 상대로 너무 강할 수 있음 |
| 보스 피해 | 보스에게만 추가 피해 | 보스 공격 창에서 `+15%` | 일반 전투에는 죽은 선택지 |
| 부상 마무리 | 낮은 체력 적 추가 피해 | 체력 25% 이하에 `+30%` | 실제 평균 이득을 UI가 설명해야 함 |
| 근거리/원거리 특화 | 거리 조건 피해 | 240px 안 또는 600px 밖에서 강화 | 수동 조준·이동 스타일과 잘 맞음 |
| 연속 명중 | 같은 대상에 누적 보너스 | 8발 연속 명중 시 최대 `+35%` | 표적 전환 시 초기화 기준 필요 |

기본 피해와 공격 속도는 가장 이해하기 쉽지만 서로 다른 계산 축이어야 한다. 둘을
한 카드에 항상 같이 넣으면 선택이 아니라 단순한 상위 레벨이 된다. 공격 속도는
성능 부하와 탄막 가독성도 같이 올리므로 Cardborne에서는 피해 증가보다 보수적으로
다뤄야 한다.

### 4. 탄도와 공격 형태 — 숫자보다 손맛을 바꾸는 아이디어

| 아이디어 | 효과 | Cardborne 적용 예 | 새로움 |
| --- | --- | --- | --- |
| 도탄 | 벽 또는 적에서 한 번 튕김 | 빗나간 탄이 가까운 적을 재탐색 | 보편적 |
| 분열탄 | 첫 명중 후 작은 탄 생성 | 2차 탄은 피해 35%, 최대 2개 | 보편적, 부하 큼 |
| 집중탄 | 여러 탄을 하나로 합침 | 확산 총구 탄 수를 1발로 압축하고 합산 피해·크기 증가 | 성능 친화적 변형 |
| 차지 탄 | 사격 유지로 한 발 강화 | 자동 연사는 유지하되 일정 주기마다 대형탄 발사 | 조작 계약을 해치지 않게 자동화 필요 |
| 관통 잔상 | 관통한 경로에 짧은 피해선 | 관통 성공 횟수에 따라 선 피해 증가 | 중간 |
| 화면 귀환탄 | 화면 밖으로 나간 탄이 반대편에서 1회 복귀 | 월드 경계와 충돌 규칙을 명확히 해야 함 | 실험적 |
| 탄막 압축 | 일정 수 이상의 같은 탄을 하나의 강한 탄으로 병합 | 시커·분열 빌드의 상한을 시각적으로 큰 탄으로 표현 | 창의적, 성능 친화적 |
| 표적 공유 | 여러 보조 무기가 같은 우선 표적에 집중 | 체력이 높은 우선 적을 빠르게 제거 | 전술적 |

Nova Drift의 탄 융합은 “더 강해지려면 더 많은 개체가 필요하다”는 전제를 깨는 좋은
레퍼런스다. Cardborne에서도 새 공격 레벨은 우선 탄 수를 유지하고 피해·크기·관통
등 기존 개체의 질을 올리는 방식이 현재 성능 상황에 맞다.

| 방어막 파쇄 보너스 | 방어막 적 파괴 시 주변 취약 | 일반 적 방어막 대응 카드 | 방어막이 없는 전투에서는 무용 |
| 체력 투자 | 최대 체력 일부를 영구 피해로 전환 | 런 동안 체력 -20%, 피해 +30% | 선택 전 결과를 정확히 표시해야 함 |
| 흡혈 과열 | 흡혈량이 찰수록 공격 상승, 피격 시 초기화 | 공격 지속 보상 | 수치 루프 상한 필요 |

### 10. 진화·변이 — 후반의 큰 전환

| 아이디어 | 조건 | 변화 | 레퍼런스 방향 |
| --- | --- | --- | --- |
| 집중 포화 | 확산 총구 최대 + 관통 최대 | 여러 탄을 거대한 관통탄 하나로 합침 | Nova Drift식 탄 융합 |
| 뇌우 핵 | 전기장 최대 + 대시 강화 | 대시 종료점에 짧은 전기장 복제 | 기본 효과의 공간 변형 |
| 절단 위성 | 회전 날개 최대 + 속도 최대 | 날개가 이동 방향 뒤에 궤적 생성 | 이동·무기 결합 |
| 지뢰 살포기 | 기뢰 최대 + 수거 범위 최대 | 아이템 수거 때 기뢰 재배치 충전 | 편의 스탯의 공격 전환 |
| 열독 반응 | 열 또는 독 최대 + 관통 최대 | 관통한 적의 상태를 뒤 적에게 전달 | 상태·탄도 결합 |
| 생존 반응로 | 체력 최대 + 흡혈 최대 | 최대 체력 초과 회복을 공격 펄스로 저장 | 방어→공격 변환 |
| 무장 해체 | 공격 카드 여러 개를 반납 | 기본탄 하나를 완전히 다른 무기로 변환 | 실험적, 되돌리기 필요 |
| 미선택 동력 | 사용하지 않은 업그레이드 포인트 보유 | 포인트당 전역 강화 | Nova Drift식 선택 보류 가치 |

진화는 단순 L5가 아니라 빌드의 규칙을 바꾸기 때문에 후반 체감은 크다. 대신 현재
5스테이지 런에서는 등장 시점, 조합 조건, 카드 설명, 실제 효과 미리보기까지 함께
설계해야 한다. 당장 필요한 화력 보정에 진화 시스템 전체를 묶으면 범위가 지나치게
커지므로 첫 구현에서는 제외하는 편이 낫다.

### 11. 성능을 함께 개선하는 업그레이드 아이디어

| 아이디어 | 플레이 효과 | 성능 효과 |
| --- | --- | --- |
| 탄 융합 | 여러 발의 총 피해를 큰 한 발로 압축 | 투사체·충돌·효과 수 감소 |
| 연쇄 상한 | 감전은 가까운 최대 4대상만 연결 | 쌍별 탐색 방지 |
| 누적 피해 정산 | 독 중첩을 폭발 한 번으로 소비 | 오래 남는 상태 틱 감소 |
| 큰 기뢰 | 기뢰 수를 늘리지 않고 한 발의 범위·피해 강화 | 월드 오브젝트 수 유지 |
| 묶음 피해 표시 | 같은 틱의 작은 숫자를 합쳐 한 번 표시 | UI/텍스트 효과 감소 |
| 시각 밀도 압축 | 같은 효과가 겹치면 밝기·크기만 합성 | 파티클/드로우 요청 억제 |

성능 친화적 업그레이드는 “약하게 보이게 만들기”가 아니라 같은 전투 결과를 더 적은
개체와 더 선명한 피드백으로 전달하는 방식이어야 한다. 현재 바로 적용할 8개 최종
레벨도 이 원칙에 맞춰 탄·날개·기뢰 수와 조회 반경을 늘리지 않는다.

## Recommendations

### 첫 구현 범위

1. 직접 피해에 기여하는 기존 8개 카드에 위 표의 최종 레벨을 한 단계씩 추가한다.
2. 3~5스테이지 제안에 호환 가능한 미완성 공격 카드 최소 1장을 보장한다.
3. `vehicle_upgrade_catalog`의 명목 상태 계약을 44로, 실제 호환 풀 소진 검증을
   최대 33 선택 구조로 갱신한다.
4. 카드 효과 미리보기와 한국어/영어 설명은 새 수치를 실제 런타임 소유자에서 읽는다.
5. 투사체·날개·기뢰 수, 공격 틱, 효과 수명, 범위는 새 최종 레벨에서 늘리지 않는다.
6. 4~5스테이지 고정 빌드 검증에서 레벨별 계산값, 제안 보장, 실제 피해 source,
   방어막 경로, 카드 풀 소진, 보스 보상 이후 흐름을 확인한다.

### 다음 후보 선정 기준

추가 카드를 만들 때는 같은 숫자의 변형을 늘리기 전에 다음 포트폴리오를 맞춘다.

- 이해가 빠른 수치 카드 30~40%
- 공격 형태·표적 선택 카드 20~30%
- 상태·조건부 조합 카드 20~25%
- 위험 보상·진화 같은 변형 카드 10~20%
- 새 투사체/지속 오브젝트를 만드는 카드에는 반드시 성능 상한을 명시

다음 신규 카드 후보로는 `연속 명중`, `방어막 관통`, `대시 장전`, `상태 임계점`,
`탄 융합`을 우선 검토한다. 각각 단일 표적 후반 화력, 방어막 지연, 수동 조작과 공격의
연결, 원소 빌드의 완성점, 성능 친화적 형태 변화를 담당해 역할 중복이 적다.

## Limitations

- 외부 게임의 시스템은 런 길이, 조작, 적 밀도, 메타 진행이 Cardborne과 다르다.
  아이디어 방향만 참고하고 수치는 현재 게임에서 다시 검증해야 한다.
- 이 문서의 새 최종 수치는 구현 전 제안값이다. 적용 후 실제 4~5스테이지 플레이와
  성능 기록에서 과도하거나 부족하면 같은 개체 수·빈도 상한 안에서 조정한다.
- 현재 성능 기준이 빨간 상태이므로 투사체 수, 공격 빈도, 연쇄 대상 수를 늘리는
  아이디어는 성능 해결 전 구현 우선순위가 낮다.
- 신규 카드 아트, 진화 UI, 재추첨 화폐, 영구 메타 진행은 이번 첫 구현 범위가 아니다.
