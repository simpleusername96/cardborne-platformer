Cardborne 보스 구현 분석 리포트

현재 코드에 구현된 12개 보스의 스탯, 공격 구성, 피해량, 발동 시간, 이동, 소환, 특수 상태와 production 이미지 에셋을 정리한 리포트입니다.

조사일 2026-08-21기준: 현재 작업 트리엔진: Godot 4.7.1범위: Stage 1–12 Boss

수정 계획과 진행 상태

요청한 코드 수정과 집중 검증 완료. 공격 이름이 아니라 실제 실행 코드로 패턴을 다시 묶었고, 보스별 수치를 Stage 배율 계산이 없는 독립 값으로 이관했습니다.

  • 구현·검증 완료 — 공유 패턴: 두 개 이상의 보스가 같은 실행 알고리즘을 사용하면 이름이 달라도 공유 동작 계열로 분류합니다.
  • 구현·검증 완료 — 보스 수치: HP, 이동, 공격 중 이동, 공격 간격과 각 패턴의 피해·범위·시간을 보스별 절대값으로 기록합니다. 일반 적의 Stage 성장 곡선은 그대로 유지합니다.
  • 구현·검증 완료 — 실행 결함: Stage 6 직접 long_bank_barrage가 거리 성장 투사체 10발을 한 번 생성하도록 연결했고, 모든 직접·자율 선택 ID가 지원 실행 경로를 갖는지 검사합니다.
  • 구현·검증 완료 — 패턴 보강: Stage 4 switch_sweep는 이제 같은 레이저의 별칭이 아니라 -0.34/0/+0.34rad 세 방향이 0.18초 간격으로 순차 발동하는 고유 패턴입니다.
  • 구현·검증 완료 — 원형 경고: 반경은 그대로 유지하면서 전체 면의 알파가 준비도에 따라 0.06→0.30으로 증가합니다. 피해 구간 경계선만 남기고 내부 채움 중첩은 제거했습니다.
  • 구현·검증 완료 — 레이저: 보스 발사 레이저는 0.45초 동안 발사점만 충전한 뒤 피해가 시작되고, 실제 충돌 길이와 화면 길이가 0.20초에 함께 완성됩니다.
  • 구현·검증 완료 — Stage 10: 처음부터 공격 가능한 상태이며, 14–15초에 얇은 반사판 예고가 나온 뒤 15–20초에만 반사판이 활성화됩니다.
  • 추가 교정: 실제 범위에 비해 걸어서 벗어날 시간이 부족했던 Stage 3 radial_pulse와 Stage 5 relay_pulse_rings의 예고를 각각 1.28초와 1.31초로 늘렸습니다.

표기 기준

예고 시간(startup)은 공격 확정부터 피해 판정 시작까지, 활성 시간(active)은 공격 판정이 유지되는 기간, 회복 시간(recovery)은 해당 행동 종료부터 다음 행동 전까지입니다.

직접 공격은 보스의 5개 패턴 순환에서 실행됩니다. 자율 공격은 별도 타이머가 직접 공격과 병행해 실행합니다. 아래 피해는 플레이어 방어 적용 전 명목 피해이며, 투사체는 한 발 기준입니다. 원형 공격은 중심·중간·외곽에 일반적으로 100%·70%·40%가 적용됩니다.
