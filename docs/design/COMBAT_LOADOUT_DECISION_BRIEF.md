# 전투 구성 결정 요약

## Context

기존 안은 근접 세 개, 활 세 개, 방패 세 개를 사거리·속도·수치로만 나눠 실제
플레이 차이가 작았다. 근접/원거리 기술도 기본 공격의 강화판이었고, 정령석은
각 장비에 여러 효과를 반복해서 붙여 액티브와 패시브의 경계가 흐렸다.

이 문서는 결정 요약만 제공한다. 구현 규칙과 수치는
`COMBAT_EQUIPMENT_CRAFTING.md`가 소유한다.

## Decision

### 전투 도구

한 영웅이 아래 세 역할을 동시에 장착한다. 전투 중 수동 교체는 없다.

| 역할 | 모델 4개 | 서로 다른 핵심 경험 |
| --- | --- | --- |
| 근접 | 여행자의 검, 사냥 창, 쌍단검, 대장장이 망치 | 연속 베기, 끝거리 찌르기, 초근접 연타, 충전 자세 파괴 |
| 원거리 | 사냥 활, 화승총, 회수 표창, 뿌리 각인판 | 충전 화살, 한 발 후 재장전, 표창 투척·회수, 적 발밑 지연 발동 |
| 방패 | 원형 방패, 소형 방패, 대형 방패, 거울 방패 | 균형 방어, 패리 전용, 고정 버티기, 투사체 저장·반사 |

새 모델은 적어도 `입력 방식`, `표적/전달`, `자원`, `약점` 중 두 가지가
달라야 한다. 숫자·색·속성만 바꾼 모델은 만들지 않는다.

### 액티브

공격과 방어 외에 **세 개까지만** 사용한다.

- `Q` 제압 기술: 적의 위치나 행동 시간을 바꾼다. 직접 피해가 주목적이면 안 된다.
- `R` 전술 기술: 영웅의 준비 상태, 적의 주목, 정보 우위를 바꾼다.
- `V` 정령술: 정령 공명을 소비하는 큰 원소 행동이다.

제압과 전술은 각각 하나를 선택한다. 정령술은 정령석이 정한다. 즉 자유롭게
고르는 추가 액티브는 두 개이고, 실제 전투 버튼은 공격·방어를 포함해 다섯 개다.

### 패시브

- 각 전투 도구의 고유 특성 1개: 도구에 포함되며 따로 장착하지 않는다.
- 장신구 효과 1개: 탐색, 보급, 소비 아이템 편의 중 하나를 선택한다.
- 정령 동조 1개: 정령석이 제공하는 조건부 원소 규칙이다.
- 런 카드: 한 런 동안 기존 행동 하나를 변형한다.

재료 등급은 피해·안정성·상태 같은 기본 수치만 올린다. 재료 등급, 방어구
수치, 소비 아이템을 패시브 스킬이라고 부르지 않는다.

## Rationale

- 원거리라는 한 역할 안에서도 조준, 재장전, 회수, 지면 지정이 달라져야
  새로운 장비를 얻은 의미가 생긴다.
- 제압·전술·정령술의 책임을 나누면 기본 공격의 강한 버전만 여러 개 생기는
  문제를 피할 수 있다.
- 추가 액티브 세 칸은 키보드와 게임패드에서 기억 가능한 상한이며, 자유 선택은
  두 칸뿐이라 준비 화면도 복잡해지지 않는다.
- 패시브는 장착 출처와 발동 조건을 보이고, HUD에는 실제 발동 때만 짧게 나타낸다.

## Consequences

- 기존 9개 설계도 목표는 12개 전투 도구 모델로 교체한다.
- `표준 화살` 하나로 모든 원거리를 처리하지 않는다. 활은 화살, 화승총은 탄약,
  투척날은 회수 수, 각인판은 집중 재사용 대기시간을 쓴다.
- 기존 근접 기술/원거리 기술은 폐기하고 제압/전술 기술로 교체한다.
- 정령석은 장비마다 세 효과를 나열하지 않고 패시브 정령 동조 하나와 액티브
  정령술 하나만 제공한다.
- HUD는 도구별 원거리 자원 하나, 방패 상태, 세 액티브만 보여준다.

## Alternatives

- 액티브를 무기별로 세 벌 만드는 안: 콘텐츠와 입력이 빠르게 늘고 같은 공격을
  반복하므로 제외했다.
- 원거리 모델을 활 세 개로 유지하는 안: 수치 조정 외에 새 경험이 없어 제외했다.
- 모든 패시브를 거대한 스킬 트리로 두는 안: 장비·장신구·정령석·카드와 책임이
  겹쳐 첫 완성 목표에서는 제외했다.
