# 전투 도구, 기술, 제작, 정령석 시스템

## Purpose

한 명의 영웅이 근접 도구, 원거리 도구, 방패를 항상 함께 갖고 다니며 상황에
따라 자연스럽게 사용하는 Cardborne의 전투·장비·성장 규칙을 정의한다. 새
장비는 공격력이나 색만 다른 복제품이 아니라 조작 리듬, 표적, 전달 방식,
자원, 위험이 다른 행동이어야 한다.

이 문서는 이전의 6개 무기 계통, 무기 A/B 수동 교체, 활 3종 중심 원거리,
장비별 인챈트, 근접/원거리 강화 기술, 추상적인 강화 랭크 설계를 대체한다.
현재 배포 코드는 아직 Warrior, Archer, Assassin 3개 프로필을 사용하므로 이
문서는 구현 완료 보고가 아니라 구현 목표다.

## Scope

이 사양이 소유하는 범위:

- 한 영웅의 전투 도구와 지원 장비 구성;
- 거리와 상황에 따른 근접/원거리 자동 선택;
- 근접 도구, 원거리 도구, 방패의 서로 다른 액티브 행동과 고유 특성;
- 제압 기술, 전술 기술, 정령술의 슬롯과 책임;
- 액티브, 고유 특성, 장신구, 정령 동조, 런 카드의 분류;
- 설계도와 재료 등급에 따른 확정 제작·재제작;
- 상태, 수리, 화살·탄약·회수날·집중 자원;
- 장비·재료·정령석·기술의 획득, 저장, 실패 방지 규칙.

맵 지형, 적 행동, 함정, 보스 패턴은 기존 콘텐츠 사양이 소유한다. 화면 배치와
시각 표현은 `PLAYER_UIUX_REFINEMENT_PLAN.md`가 소유한다. 어떤 장비나 기술도
필수 점프, 더블 점프, 대시, 줄타기, 숙이기, 낙하 복귀를 대체하지 않는다.

## Domain Brief

- **요청 해석:** 무기 목록을 늘리는 RPG가 아니라, 세 전투 역할 안에서 실제
  행동이 다른 작은 액션 게임을 만든다. 총, 투척날, 마법도 원거리 역할을
  수행할 수 있으며 활의 수치 변형으로 취급하지 않는다.
- **전투 도구 경계:** 공격/방어 의도와 전투 스냅샷을 받아 정확히 한 액티브
  행동을 결정한다. UI 노드, 저장 파일, 드롭 확률은 알지 못한다.
- **기술 경계:** 제압은 적의 공간과 행동 시간, 전술은 영웅의 준비·주목·정보,
  정령술은 공명으로 만드는 큰 원소 결과만 소유한다.
- **패시브 경계:** 입력 없이 선언된 조건에서만 발동한다. 액티브 버튼, 별도
  조준, 숨은 소비 입력을 요구하면 패시브가 아니다.
- **제작 경계:** 설계도, 재료 등급, 제작식, 결과 장비를 검증한다. 전투 중
  직접 능력치를 수정하거나 무작위 옵션을 만들지 않는다.
- **보상 경계:** 적·상자·NPC·스테이지 보상을 한 번만 정산한다. 보이는 필드
  아이템과 실제 보상 거래를 분리한다.
- **불변 규칙:** 상태 0, 화살/탄약 0, 회수날 이탈, 정령 집중 소진만으로 진행이
  막히지 않는다. 기본 장비와 기본 이동으로 모든 필수 구간을 완료할 수 있다.
- **단순 CRUD 여부:** 아니다. 입력 판정, 표적 정책, 전투 상태, 자원 회복,
  보상 중복 방지, 저장 경계가 서로 영향을 준다.

## Product Contract

> 플레이어는 전투 중 무기 메뉴를 열지 않는다. 가까운 위협은 장착한 근접
> 도구로, 먼 위협은 장착한 원거리 도구 고유 방식으로 상대하며, 방어 입력은
> 언제나 장착한 방패를 사용한다. 제압·전술·정령술은 기본 공격을 복제하지
> 않고 각각 공간, 준비, 큰 원소 전환점을 담당한다.

성장은 네 가지 질문으로 읽혀야 한다.

1. **도구:** 다음 스테이지에 어떤 근접·원거리·방패 행동을 가져갈까?
2. **기술:** 적을 움직일 제압과 전투를 준비할 전술 중 무엇을 장착할까?
3. **정령:** 어떤 패시브 동조와 액티브 정령술을 한 묶음으로 가져갈까?
4. **투자:** 익숙한 도구를 좋은 재료로 다시 만들까, 새 행동을 여는 설계도를
   먼저 제작할까?

## Canonical Terms

플레이어에게는 아래 한국어 명칭을 사용한다. 괄호의 영문은 코드와 개발 문서
검색을 위한 보조어이며 게임 화면의 기본 표기가 아니다.

| 표준 용어 | 의미 | 사용하지 않을 표현 |
| --- | --- | --- |
| **전투 도구** (`combat tool`) | 근접 도구, 원거리 도구, 방패 세 슬롯 전체. | 무기 A/B, 클래스 장비 |
| **근접 도구** (`melee tool`) | 가까운 위협에 반복 피해를 주는 장비. 검·창·단검·망치를 포함한다. | 단거리 클래스 |
| **원거리 도구** (`ranged tool`) | 먼 위협을 투사체, 재장전, 표창 회수, 지면 지정 방식으로 해결하는 장비. | 활 전용 슬롯, 보조 무기 |
| **방패** (`guard tool`) | 방어 입력으로 피해를 막거나 패리·버티기·투사체 반사를 수행하는 장비. | 근접 무기 부속품 |
| **도구 모델** (`tool model`) | 실제 조작과 전투 정체성을 가진 장비 종류. | 스킨, 수치 프리셋 |
| **설계도** (`blueprint`) | 하나의 도구 모델 제작을 영구 해금하는 지식. 설계도 자체는 장비가 아니다. | 희귀도, 랜덤 옵션 |
| **재료 등급** (`material grade`) | 같은 모델을 더 좋은 재료로 다시 만들 때의 품질 단계. | 강화 +1/+2/+3 |
| **재제작** (`recraft`) | 보유 설계도와 상위 재료로 같은 모델을 새로 만드는 확정 작업. | 확률 강화, 인챈트 |
| **상태** (`condition`) | 근접 도구와 방패가 사용으로 마모된 정도. 0이어도 파괴되지 않는다. | 파괴 확률 |
| **액티브 행동** (`active action`) | 플레이어 입력이 있어야 실행되는 행동. | 패시브 효과 |
| **고유 특성** (`intrinsic trait`) | 도구 모델에 포함되어 조건 충족 시 자동 발동하는 한 가지 패시브. | 별도 스킬 슬롯 |
| **제압 기술** (`control skill`) | 적의 위치나 행동 시간을 바꾸는 선택 액티브. | 강공격 |
| **전술 기술** (`tactical skill`) | 영웅의 준비 상태, 적의 주목, 정보 우위를 바꾸는 선택 액티브. | 두 번째 제압 기술 |
| **정령석** (`Spirit Stone`) | 정령 동조와 정령술을 한 묶음으로 제공하는 핵심 장비. | 무기 소켓 보석 |
| **정령 동조** (`spirit attunement`) | 정령석이 제공하는 입력 없는 조건부 패시브. | 상시 속성 부여 |
| **정령술** (`Spirit Art`) | 공명을 소비해 실행하는 정령석 고유 액티브. | 네 번째 자유 기술 |
| **공명** (`resonance`) | 직접 공격·정밀 방어·제압/전술 성공으로 채우는 정령술 자원. | 마나 물약 |
| **장신구** (`accessory`) | 탐색·보급·소비 편의 중 하나를 바꾸는 패시브 장비. | charm, 참 |
| **런 카드** (`run card`) | 한 런 동안 기존 행동 하나의 조건이나 결과를 바꾸는 임시 변형. | 영구 패시브 트리 |

## Functional Ownership

같은 기능을 여러 시스템이 소유하지 않는다.

| 기능 | 단일 소유자 | 다른 요소가 하면 안 되는 일 |
| --- | --- | --- |
| 반복 가능한 근거리 피해 | 근접 도구 액티브 | 제압/전술 기술이 더 좋은 기본 공격이 됨 |
| 반복 가능한 원거리 위협 해결 | 원거리 도구 액티브 | 정령술이 항상 쓸 수 있는 원거리 기본 공격이 됨 |
| 반응형 피해 완화·패리·반사 | 방패 액티브 | 방어구나 전술 기술이 방어 입력을 대체함 |
| 적 위치·행동 시간 변경 | 제압 기술 | 높은 직접 피해로 기본 공격까지 담당함 |
| 영웅 준비·적 주목·전투 정보 | 전술 기술 | 적을 끌고 밀어 제압까지 담당함 |
| 공명을 쓰는 큰 원소 전환점 | 정령술 | 낮은 비용으로 반복되어 도구를 대체함 |
| 도구의 입력 없는 정체성 | 고유 특성 | 별도 장착 슬롯이나 수동 입력을 요구함 |
| 정령의 낮은 빈도 원소 규칙 | 정령 동조 | 장비마다 세 효과를 중복 등록함 |
| 탐색·보급·소비 편의 | 장신구 | 직접 전투 액티브나 큰 피해를 제공함 |
| 영구 직접 수치 성장 | 재료 등급 | 새 행동, 조건부 발동, 무작위 옵션을 추가함 |
| 한 런의 행동 변형 | 런 카드 | 영구 장비 성장이나 새 버튼을 만듦 |
| 긴급 회복·수리·보조 | 소비 아이템 | 반복 기본 행동이나 상시 패시브가 됨 |

### 중복 금지 게이트

모든 전투 도구, 기술, 정령술은 다음 여섯 항목으로 기능 서명을 작성한다.

1. **활성:** 누르기, 유지, 놓기, 연속 입력, 반응 입력 중 무엇인가?
2. **주 표적:** 자기 자신, 단일 적, 지면, 범위, 투사체 중 무엇인가?
3. **전달:** 직접 타격, 직선 투사체, 곡사, 회수, 지연 발생 중 무엇인가?
4. **자원:** 상태, 탄약, 배치 수, 재사용 대기시간, 공명 중 무엇인가?
5. **주 결과:** 피해, 방어, 위치 변경, 행동 중단, 준비, 정보 중 무엇인가?
6. **명시적 약점:** 실패하거나 불리한 대상·거리·시간은 무엇인가?

신규 요소는 기존 요소와 적어도 두 개의 핵심 항목이 달라야 하고, 반드시 한
가지 약점이 있어야 한다. `피해 +10%`, 다른 색의 투사체, 같은 동작의 원소
변경은 새 요소로 인정하지 않는다. 같은 역할 슬롯의 선택지끼리는 주 목적이
같을 수 있지만 입력·전달·자원·약점이 달라야 한다.

## Target Content Envelope

첫 완성 목표는 아래 수를 넘기지 않는다. 신규 콘텐츠는 새 계층을 만들기보다
기존 슬롯 안에서 실제 선택을 추가해야 한다.

| 콘텐츠 | 목표 수 | 동시에 장착/사용 |
| --- | ---: | ---: |
| 전투 도구 역할 | 3 | 근접 1 + 원거리 1 + 방패 1 |
| 전투 도구 모델/설계도 | 12 | 역할별 1, 역할마다 4개 후보 |
| 재료 등급 | 3 | 제작 장비별 1 |
| 제압 기술 | 3 | 1 |
| 전술 기술 | 3 | 1 |
| 정령석/정령술 | 4 | 정령석 1이 동조 1 + 정령술 1 제공 |
| 방어구 | 3 | 1 |
| 장신구 | 4 | 1 |
| 소비 아이템 | 3 | 1 |

전투 중 사용하는 추가 액티브는 제압, 전술, 정령술 **세 개가 상한**이다.
제압과 전술만 자유 선택하고 정령술은 정령석이 정하므로 자유 액티브 선택은
두 개다. 콘텐츠 후보 수가 늘어도 동시 액티브 슬롯 수는 늘리지 않는다.

## Equipment Loadout

스테이지 진입 전 준비 화면에서 다음 슬롯을 확정한다.

| 슬롯 | 수 | 역할 | 제외되는 책임 |
| --- | ---: | --- | --- |
| 근접 도구 | 1 | 가까운 적 반복 피해와 근접 압박. | 필수 이동, 방어, 원거리 해결 |
| 원거리 도구 | 1 | 먼 적을 고유 표적·자원 방식으로 해결. | 모든 거리의 자동 정답 |
| 방패 | 1 | 전면 방어, 패리, 버티기, 반사 중 하나. | 모든 공격 무효화 |
| 제압 기술 | 1 | 적 공간 또는 행동 시간을 바꿈. | 직접 피해 주력 |
| 전술 기술 | 1 | 준비, 주목, 정보를 바꿈. | 제압 또는 이동 능력 대체 |
| 정령석 | 1 | 정령 동조 1개와 정령술 1개. | 장비별 원소 소켓 |
| 방어구 | 1 | 피해 완화와 이동 부담의 교환. | 별도 기술 트리 |
| 장신구 | 1 | 탐색·보급·소비 편의 하나. | 전투 액티브 |
| 소비 아이템 | 1 | 회복, 긴급 수리, 정령 보조 중 하나. | 여러 퀵슬롯 |

전투 중에는 장비를 교체하지 않는다. 세 전투 도구는 모두 현재 장비이며 입력과
상황이 사용할 도구를 고른다. 장비, 기술, 정령석 변경과 제작은 준비 구역이나
대장간에서만 가능하다.

| 방어 | `G` | `Y` | 장착 방패 액티브 실행. |

별도 `Heavy Attack`과 무기 전환 버튼은 두지 않는다. 느리고 강한 입력은 망치
유지 공격, 화승총 재장전처럼 도구 액티브 자체가 소유한다. 제압/전술/정령술은
공격 더블 탭이나 방향 조합에 숨기지 않는다. 모든 입력은 재지정 가능해야 하며,
게임패드에서 한 버튼에 두 전투 행동을 겹치지 않는다.

## Context Attack Resolution

공격 입력 한 번은 다음 순서로 정확히 하나의 행동을 결정한다.

1. 바라보거나 조준한 방향의 공격 가능한 표적 스냅샷을 만든다.
2. 현재 근접 도구의 실제 도달 범위에 적이 있으면 가장 가까운 적에 대한 근접
   행동을 선택한다.
3. 근접 후보가 없으면 장착 원거리 도구의 표적 정책에 같은 스냅샷을 전달한다.
4. 원거리 정책이 유효한 표적·지면·자원을 반환하면 해당 도구 행동을 선택한다.
5. 유효한 원거리 의도가 없으면 바라보는 방향으로 근접 행동을 선택한다.
6. 선택 결과는 행동 시작 시 고정하며 회복이 끝날 때까지 바꾸지 않는다.

공통 규칙:

- 뒤에 있는 적, 화면 밖 적, 아직 발견하지 않은 적은 자동 표적이 아니다.
- 직선 도구는 벽 너머 적을 고르지 않는다. 지면 지정 도구도 대상 자체는
  보여야 하며, 유효한 발밑 지면이 있어야 한다.
- 근접/원거리 경계에는 최소 32px 완충 구간과 마지막 선택 유지 규칙을 둔다.
- 상자와 NPC는 공격 표적이 아니다. 파괴 가능 장애물은 명시적 전투 표적만 된다.
- UI 미리보기와 실제 행동은 같은 불변 `AttackIntent`를 사용한다.
- 자원이 부족한 원거리 도구의 빈 동작은 나오지 않는다. 미리보기부터 근접으로
  돌아가거나 도구 고유 복구 동작을 명확히 표시한다.

### 원거리 표적 정책

| 도구 | 후보 선택 | 추가 검증 | 실패 결과 |
| --- | --- | --- | --- |
| 사냥 활 | 조준 방향과 가까운 보이는 적 | 직선 시야, 화살, 유효 거리 | 근접 행동 |
| 화승총 | 조준 방향과 가까운 보이는 적 | 직선 시야, 장전 상태, 탄약 | 장전 중이면 장전 표시, 아니면 근접 행동 |
| 회수 표창 | 전방 부채꼴의 가장 가까운 적 | 표창 수, 왕복 경로의 첫 벽 | 유지 입력이면 회수, 아니면 근접 행동 |
| 뿌리 각인판 | 전방에서 가장 가까운 보이는 원거리 적 | 지상 적, 발밑 유효 지면, 집중 | 표식·집중 소모 없이 근접 행동 |

뿌리 각인판은 직선 투사체 경로가 필요 없어서 낮은 엄폐 뒤의 보이는 적을
공격할 수 있다. 대신 공중 적, 발밑이 없는 적, 완전한 벽 뒤 적은 고르지 않는다.
표식이 0.3초 동안 보인 뒤 뿌리가 솟으며, 표적이 유효 지면을 떠나면 빗나간다.

- 기술로만 통과 가능한 필수 지형, 비밀이 아닌 진행문, 보스 패턴은 금지한다.

## Spirit Stones

정령석은 금속에 임의 속성을 붙이는 소켓이 아니다. 영웅이 한 정령과 계약해
낮은 빈도의 정령 동조와 공명을 쓰는 정령술을 함께 빌린다는 설정이다.

- 한 번에 정령석 하나만 장착한다.
- 정령석 하나는 **패시브 정령 동조 1개**와 **액티브 정령술 1개**만 제공한다.
- 무기마다 별도 원소 효과를 등록하지 않는다.
- 정령석은 등급, 랜덤 옵션, 내구도, 확률 강화가 없다.
- 직접 공격, 정밀 방어, 제압/전술의 유효 성공으로 공명을 채운다.
- 같은 이벤트가 공격·패시브·정령술에 중복 정산되지 않도록 이벤트 ID를 쓴다.
- 정령석 교체는 준비 구역에서 무료로 한다.

| 정령석 | 정령 동조 (패시브) | 정령술 (액티브) | 명시적 약점 |
| --- | --- | --- | --- |
| **불꽃 정령석** | 3초 안의 네 번째 직접 공격이 짧은 화상을 남긴다. | **화염 쇄도:** 전방 직선에 큰 불꽃 파동을 보낸다. | 연속 적중이 끊기면 동조가 초기화되고 단일 분산 적에 비효율적. |
| **서리 정령석** | 정밀 방어 성공 시 공격자에게 짧은 냉기를 건다. | **고요한 겨울:** 주변 투사체를 잠시 멈추고 범위 안 적을 둔화한다. | 직접 폭발 피해가 낮고 방어 불가 공격에는 동조가 없다. |
| **폭풍 정령석** | 제압 또는 전술 성공 뒤 다음 직접 공격이 가까운 한 적에게 약하게 연쇄된다. | **하늘의 실:** 보이는 적 최대 4명을 잇는 번개를 내리며 공중 적을 우선한다. | 단일 적에게는 총 효율이 낮고 엄폐 뒤 적을 고르지 않는다. |
| **맹독 정령석** | 2초 이상 공격하지 않은 뒤의 첫 직접 공격이 독을 1회 적용한다. | **독무:** 선택한 보이는 지점에 잠시 남는 독 구름을 만든다. | 빠른 연타에서는 동조 빈도가 낮고 이동이 빠른 적은 구름을 벗어난다. |

정령 동조와 정령술은 같은 원소라도 별도 정의와 설명을 가진다. 동조는 입력이
없고 낮은 빈도로 발동하며, 정령술은 공명 가득 참과 `V` 입력이 필요하다.

## Blueprints And Material Grades

### 두 성장 방향

1. **동일 모델 재제작:** 익숙한 도구를 상위 재료로 다시 만들어 직접 성능과
   신뢰도를 높인다.
2. **새 모델 제작:** 입력 리듬, 표적, 전달, 자원, 약점이 다른 행동을 연다.

새 모델이 항상 이전 모델의 상위 호환은 아니다. 순수 수치 상승은 재료 등급이
담당하고 도구 모델은 플레이 방식을 담당한다. 최고 재료 여행자의 검과 사냥
활도 후반에 유효해야 한다.

### 재료 계열과 등급

| 계열 | 일반 1등급 | 정제 2등급 | 장인 3등급 | 주 사용처 |
| --- | --- | --- | --- | --- |
| 금속 | 철 조각 | 강철 조각 | 담금질 합금 | 칼날, 총신, 방패, 중량 방어구 |
| 목재 | 일반 목재 | 단단한 나무 | 오래 묵은 심재 | 손잡이, 활, 개머리판, 방패 |
| 섬유 | 거친 섬유 | 질긴 섬유 | 촘촘한 직물 | 활시위, 투척날 끈, 각인판, 경량 방어구 |
| 가죽 | 보통 가죽 | 강화 가죽 | 수호수 가죽 | 손잡이, 방어구, 주머니, 거울 방패 틀 |

화약 주머니는 화승총 탄약 제작에만 쓰는 무등급 보급품이다. 영구 장비 성장
재료나 다섯 번째 재료 등급이 아니다. 보스 핵은 완주 후 장인 제작 한 건을 여는
고유 보상이며 일반 적 드롭이나 반복 화폐로 쓰지 않는다.

재료 등급 하나가 올라갈 때의 초기 범위:

- 직접 피해 또는 방어 안정성 `+12%`에서 `+18%`;
- 근접 도구와 방패 최대 상태 약 `+20%`;
- 시작/회복 시간 변화 최대 `5%`;
- 도달 거리, 공격 폭, 표적 정책, 자원 최대치, 고유 특성은 변화 없음.

### 모델별 기본 제작식

| 도구 모델 | 같은 등급 제작 비용 |
| --- | --- |
| 여행자의 검 | 금속 5 + 목재 2 |
| 사냥 창 | 금속 3 + 목재 4 |
| 쌍단검 | 금속 6 + 섬유 2 |
| 대장장이 망치 | 금속 6 + 목재 3 |
| 사냥 활 | 금속 2 + 목재 5 + 섬유 3 |
| 화승총 | 금속 6 + 목재 3 + 섬유 1 |
| 회수 표창 | 금속 5 + 섬유 2 + 가죽 1 |
| 뿌리 각인판 | 금속 1 + 목재 3 + 섬유 3 + 가죽 2 |
| 원형 방패 | 금속 3 + 목재 4 + 가죽 2 |
| 소형 방패 | 금속 4 + 가죽 2 |
| 대형 방패 | 금속 6 + 목재 4 + 가죽 3 |
| 거울 방패 | 금속 4 + 섬유 3 + 가죽 2 |

상위 재료 재제작은 항상 확정 성공한다. 실패, 파괴, 등급 하락, 무작위 능력치
재추첨이 없다. 확인 화면은 현재 모델과 결과 모델, 액티브/고유 특성, 재료별
수치 기여, 비용, 남는 재료를 분리해서 보여준다.

## Condition And Repair

마모는 준비와 재료 소비에 의미를 주되 플레이를 중단시키면 안 된다.

- 근접 도구와 방패만 상태를 가진다. 원거리 도구는 각자 자원·회복 규칙이 있어
  별도 상태를 겹치지 않는다.
- 근접 도구는 적중한 직접 공격 8회마다 상태 1을 잃는다. 망치 완전 충전으로
  중장갑·단단한 물체를 맞히면 상태 2를 잃는다.
- 방패는 일반 방어 성공 시 1, 강한 공격 방어 시 3을 잃는다. 정밀 방어는 0
  또는 1만 잃는다.
- 상태 30% 이하에서는 해당 도구 실루엣과 짧은 소리로 경고한다.
- 상태 0은 **마모됨**이다. 도구는 사라지지 않는다. 근접 피해 또는 방패
  안정성 `-15%`, 회복 시간 `+10%`만 적용한다.
- 대장간에서 같은 등급 주 재료 1개로 상태 35%를 복구한다.
- 스테이지 진입 전 장착 도구가 25% 미만이면 25%까지 무료 기본 정비한다.
- 현장 수리 도구는 근접 도구 또는 방패 하나를 35% 복구한다.
- 상태가 낮거나 재료가 없어도 스테이지 진입을 막지 않는다.

## Ranged Resources And Supply

| 원거리 도구 | 전투 자원 | 기본/최대 | 스테이지 최소 보장 | 보급 지점 결과 |
| --- | --- | ---: | ---: | --- |
| 사냥 활 | 화살 | 12 / 20 | 일반 8, 보스 12 | 화살 4발 |
| 화승총 | 탄약 + 장전 | 5 / 8 | 일반 4, 보스 6 | 탄약 2발, 비전투면 장전 완료 |
| 회수 표창 | 재사용 표창 | 3 / 3 | 항상 3개 소유 | 배치된 표창 즉시 안전 회수 |
| 뿌리 각인판 | 집중 | 2회, 순차 회복 | 스테이지 시작 시 가득 참 | 집중 전부 회복 |

- 맵의 `ranged_supply` 지점은 스테이지 조립 시 장착 도구에 맞는 실제 물체와
  이름으로 바뀐다. 화살 묶음이 총알로 보이거나 추상 보석으로 통일되지 않는다.
- 회수 표창이 낭떠러지·화면 밖으로 나가면 1.5초 뒤 안전 회수된다. 적이
  소유권을 빼앗거나 영구 분실시키지 않는다.
- 뿌리 각인판 집중은 시간으로 회복하며 별도 소비 인벤토리를 만들지 않는다.
- 화살 8발은 일반 금속 1 + 일반 목재 1로 제작한다.
- 화승총 탄약 4발은 일반 금속 1 + 화약 주머니 1로 제작한다. 화약은 고정
  보급함, 사수형 적, 상점에서 얻고 스테이지 최소 보장에는 비용이 없다.
- 화살·탄약 부족 때문에 이전 지역을 의무 반복하게 만들지 않는다. 재도전은
  더 빠른 제작과 선택적 준비를 위한 것이다.

## Loot, Materials, And Reward Delivery

- 적의 재료 보상이 결정되면 사망 지점과 가장 가까운 안전한 바닥에 실제
  아이템을 생성한다.
- 금속은 파편, 목재는 짧은 묶음, 섬유는 감긴 실, 가죽은 접힌 조각, 화약은
  봉한 주머니로 형태를 구분한다. 등급은 테두리와 표식으로 추가 구분한다.
- 일반 재료는 짧게 튀고 0.35초 뒤 플레이어에게 끌려오며 접촉 시 자동 획득한다.
- 낭떠러지로 떨어지거나 전투 종료 시 남으면 안전 회수한다.
- 화살 묶음, 탄약 주머니, 회수날 신호, 집중 흔적은 장착 원거리 도구와 맞는
  경우에만 나타나며 실제 자원 변화량을 수령 문구로 보여준다.
- 중요한 설계도, 기술서, 정령석은 자동 흡수하지 않는다. 상자·NPC·제단에서
  `E`로 확인하고 `액티브`, `고유 특성`, `패시브` 중 무엇을 여는지 표시한다.
- HUD는 재료 총량을 항상 나열하지 않는다. 획득 순간 아이콘, 이름, 수량,
  용도를 짧게 보여주고 준비 화면에서 전체 재고를 확인한다.
- 보이는 아이템과 보상 거래는 하나의 거래 ID를 공유해 저장 복구 후에도 한 번만
  적용된다.

재료 등급은 익숙한 모델의 직접 성능을 올리고, 기술은 공간·준비 방식, 정령석은
동조·정령술 묶음, 카드는 한 런의 변형을 담당한다.

| **Slime Court** | 보스 핵과 완주 정산 | 선택 장인 재제작 할인 | 모든 계열, 보스 핵 |

연습장은 근접, 원거리, 방어, 제압, 전술을 짧은 구간으로 하나씩 보여준다.
건너뛰면 기본 세 도구, 기본 제압/전술, 회복 물약, 선택한 첫 정령석, 설명 완료
상태를 동일하게 지급한다. 건너뛰기는 보상 손실이나 약한 시작을 만들지 않는다.

## Stage Replay Rules

이전 지역 재도전은 다음 목적만 가진다.

- 놓친 고정 설계도, 기술서, NPC 의뢰, 정령 시련 회수;
- 공개된 재료 계열을 더 모아 원하는 재제작을 앞당김;
- 새 전투 도구·기술 조합 연습.

첫 완료 설계도·정령석·보스 핵은 한 번만 지급한다. 반복 보상은 예상 재료와
최소 수량을 진입 전에 공개한다. 다음 필수 스테이지 해금, 무료 최소 보급,
기본 수리, 기본 회복은 무작위 드롭이나 반복 횟수에 의존하지 않는다.

## Persistence Contract

프로필 저장:

- 설계도, 제압/전술 기술, 정령석 해금;
- 보유 재료와 화약;
- 제작한 도구의 모델, 재료 등급, 현재 상태;
- 장착 전투 도구, 기술, 정령석, 지원 장비;
- 연습장 완료/건너뛰기와 고정 보상 거래 기록;
- 입력 설정과 프로필 메타데이터.

런 중단 저장:

- 현재 스테이지와 승인된 체크포인트;
- 장착 도구·기술·정령석 스냅샷;
- 상태, 화살, 탄약, 회수날 상태, 집중, 공명;
- 체력, 소비 아이템, 카드, 임시 효과;
- 이미 정산된 적·상자·설계도·기술서·정령석 거래 ID.

저장 복구는 장면 트리를 직렬화하지 않는다. 체크포인트에서 스테이지를 다시
조립하고 거래 기록으로 중복 보상을 막는다. 회수날은 복구 시 모두 영웅에게
돌아오고, 뿌리 각인판 집중은 저장된 값을 유효 범위로 제한한다.

## Requirements

- [ ] 생산 화면에는 클래스 선택, 무기 A/B 교체, 전투 중 무기 휠이 없다.
- [ ] 한 영웅이 근접 도구, 원거리 도구, 방패를 동시에 장착한다.
- [ ] 12개 도구 모델은 기능 서명에서 적어도 두 축과 한 약점이 다르다.
- [ ] 각 도구 설명은 액티브 행동과 고유 특성을 별도 항목으로 표시한다.
- [ ] 공격 판정은 같은 위치·표적·자원 상태에서 항상 같은 행동을 선택한다.
- [ ] 선택 행동과 실제 공격/방어 범위가 같은 의도로 미리 보인다.
- [ ] 활, 화승총, 회수 표창, 뿌리 각인판은 별도 표적·자원 정책을 쓴다.
- [ ] 방어 입력은 항상 장착 방패를 사용하고 네 모델의 실패 조건을 보존한다.
- [ ] 추가 액티브는 제압, 전술, 정령술 세 슬롯을 넘지 않는다.
- [ ] 제압은 적 공간/시간, 전술은 준비/주목/정보, 정령술은 공명 원소 결과만 소유한다.
- [ ] 패시브는 도구 고유 특성, 장신구, 정령 동조, 런 카드로 출처가 구분된다.
- [ ] 정령석 하나는 정령 동조 하나와 정령술 하나만 제공한다.
- [ ] 재료 등급은 직접 수치만 바꾸고 새 행동이나 무작위 옵션을 만들지 않는다.
- [ ] 제작·수리는 실패, 파괴, 등급 하락, 무작위 재추첨이 없다.
- [ ] 상태 0, 화살/탄약 0, 회수날 이탈, 집중 소진으로 진행이 막히지 않는다.
- [ ] 적 재료와 보급품은 안전한 실제 필드 아이템과 한 번만 적용되는 거래로 연결된다.
- [ ] 설계도, 기술, 정령석은 고정 획득처가 있고 무작위로 영구 유실되지 않는다.
- [ ] 모든 필수 이동 경로는 전투 도구, 기술, 정령석과 무관하게 통과 가능하다.

## Acceptance Criteria

1. 기본 도구·기술·정령석만 가진 새 프로필로 세 일반 스테이지와 보스를
   완료할 수 있다.
2. 플레이어가 5분 연습 뒤 상황 공격, 방어, 제압, 전술, 정령술의 책임을
   서로 바꾸어 설명하지 않는다.
3. 각 도구 모델을 60초씩 사용했을 때 다른 모델과 다른 입력 리듬·표적·자원·
   약점 중 적어도 두 가지를 플레이어가 식별한다.
4. 가까운 적, 먼 적, 벽 뒤 적, 공중 적, 이동 적, 지면 없는 적, 자원 0,
   경계 거리, 다수 표적에서 네 원거리 정책이 자동화 테스트로 재현된다.
5. 뿌리 각인판 표식과 실제 지면 발생 위치, 활/총/투척날 궤적과 실제 판정이
   허용 오차 안에서 일치한다.
6. 제압 기술은 직접 피해 주력으로 쓰이지 않고, 전술 기술은 적을 직접 끌거나
   밀지 않으며, 정령술은 공명 없이 반복되지 않는다.
7. 액티브/패시브/고유 특성/런 효과가 준비 화면과 획득 화면에서 별도 표제로
   표시되고 HUD에는 필요한 전투 상태만 남는다.
8. 같은 모델을 상위 재료로 재제작했을 때 비교 화면과 실제 값이 일치하고
   행동·표적 정책은 바뀌지 않는다.
9. 상태 0과 원거리 자원 0으로 준비 화면에 들어가도 무료 최소 정비·보급 후
   다음 스테이지를 시작할 수 있다.
10. 적 재료, 보급, 상자, 퀘스트, 첫 완료, 반복 완료 보상이 저장/복구 후에도
    정확히 한 번 적용된다.
11. 연습장 완료와 건너뛰기가 같은 기본 도구·기술·정령석 선택·설명 완료
    상태를 만든다.
12. UI는 `PLAYER_UIUX_REFINEMENT_PLAN.md`의 상태, 포커스, 화면 크기, 피드백
    검증을 통과한다.

## Non-Goals

- 전투 중 무기 휠, 무기 A/B 교체, 여러 영웅 또는 클래스 선택;
- 검·창·총·마법마다 별도 5개 기술 세트를 만드는 일;
- 추가 액티브 네 개 이상 또는 모든 해금 기술 동시 사용;
- 액티브와 패시브를 한 스킬 목록에 혼합;
- 랜덤 희귀도, 무작위 접두/접미사, 확률 강화, 장비 파괴;
- 무기별 원소 소켓, 원소 탄약 인벤토리, 정령석 등급 뽑기;
- 투구·장갑·바지·신발까지 나누는 다중 방어구 슬롯;
- 기본 보급이나 수리를 위한 의무 반복 플레이;
- 장비·기술로만 통과하는 필수 점프, 로프, 대시 경로;
- 현재 고정 스테이지 검증 전에 런타임 랜덤 지형 생성을 다시 활성화하는 일.
