# 플레이어 UI/UX 개선 계획

## Purpose

현재의 기능 확인용 텍스트 중심 화면을 실제 게임처럼 읽히는 흐름으로 교체한다.
플레이어가 설명문을 읽지 않아도 다음 행동, 공격에 사용될 장비, 방어 가능 여부,
획득한 보상, 제작 결과, 저장 상태를 알 수 있어야 한다.

이 계획은 화면과 상호작용만 소유한다. 근접/원거리 자동 선택, 제작 비용,
정령석 효과, 내구 상태, 화살 보급 같은 게임 규칙은
`COMBAT_EQUIPMENT_CRAFTING.md`를 그대로 표시하며 UI에서 다시 계산하지 않는다.

## UX Direction

- **표면:** 2D 액션 게임의 플레이 HUD와 스테이지 사이 준비 화면.
- **주요 사용자 작업:** 싸우는 동안 즉시 판단하고, 안전 구역에서는 장비와 다음
  목표를 비교해 확정한다.
- **방향:** 차분한 폐허 탐험 분위기, 게임 플레이를 가리지 않는 얇은 HUD,
  실루엣과 짧은 동작 피드백 우선.
- **밀도:** 전투 화면은 낮음, 준비·제작 화면은 중간. 재료 전체 목록과 긴 설명은
  전투 화면에 상시 노출하지 않는다.
- **개선 방식:** 기존 생산 UI의 입력 리매핑, 보상 트랜잭션, 포커스 처리,
  반응형 재배치, 공통 스타일은 재사용한다. 클래스와 디버그 성격의 표현만 교체한다.
- **금지:** 마케팅 랜딩 페이지, 설명용 거대 텍스트, 중첩 카드, 작동하지 않는
  메뉴, raw ID, 화면을 덮는 반투명 패널, 색만으로 구분하는 상태.

| 텍스트 | 영문 대문자, 개발 용어, 축약 재료명, 설명문이 화면 기능을 대신하는 곳이 있음. | 일반 게임 UI가 아니라 테스트 상태 보고처럼 보임. |

## To-Be Flow

```text
메인 메뉴
 -> 프로필 선택 또는 Continue
 -> 새 프로필: 무기 연습장 / 동일 보상으로 건너뛰기
 -> 장비 준비: 근접 / 원거리 / 방패 / 방어구 / 장신구 / 정령석 / 소비 아이템
 -> 스테이지 지도: 첫 보상, 반복 보상, 놓친 설계도, 추천 준비 확인
 -> 스테이지 HUD
    -> 필드 아이템과 보상 수령
    -> 레벨/카드 선택
    -> 일시정지/설정
 -> 결과 요약
 -> 대장간: 제작 / 재제작 / 수리 / 화살 보급
 -> 다음 스테이지 또는 이전 지역 재도전
 -> 보스
 -> 런 정산 / 프로필 저장
```

원칙:

- 한 화면의 주요 행동은 하나다. 장비 준비는 장착, 대장간은 제작/수리,
  스테이지 지도는 진입 결정에 집중한다.
- 모달 보상은 전투를 멈추고 중복 확정을 막는다.
- 화면 전환을 시작한 버튼은 진행 상태로 바뀌며 연속 입력을 받지 않는다.
- 취소 가능한 화면과 반드시 받아야 하는 보상을 명확히 구분한다.
- 생산 화면에 테스트, seed, route, validation, raw content ID를 노출하지 않는다.

## Information Architecture

### 메인 메뉴와 프로필

메인 메뉴 순서:

1. **계속하기:** 유효한 체크포인트 저장이 있을 때만 표시.
2. **새 게임:** 기존 중단 저장이 있으면 계속/포기 선택을 먼저 요구.
3. **프로필:** 로컬 슬롯 3개.
4. **연습장:** 완료 후에도 다시 입장 가능.
5. **설정.**
6. **종료.**

프로필 슬롯은 플레이 시간, 마지막 안전 지점, 완료한 최고 스테이지, 마지막
장비 구성을 보여준다. 비어 있는 슬롯은 `새 프로필`만 제공한다. 삭제는 슬롯
이름을 명시하고 길게 누르기 또는 두 번째 확인을 요구한다.

저장 상태는 `저장 중`, `저장됨`, `복구된 백업`, `저장 실패` 네 상태를 갖는다.
실패 시 플레이를 즉시 종료시키지 않고 다시 시도와 안전한 메뉴 복귀를 제공한다.

### 장비 준비

장비 준비 화면의 첫 화면에는 일곱 슬롯을 한 번에 보여주되, 각 슬롯은 아이콘,
이름, 재료 등급, 핵심 장단점 한 줄만 표시한다.

```text
전투 장비:  [근접] [원거리] [방패]
보조 장비:  [방어구] [장신구] [정령석] [소비 아이템]
기술:       [근접 Q] [원거리 R] [정령 V]
```

- 슬롯을 선택하면 같은 종류의 보유 설계도만 목록에 나타난다.
- 비교는 `현재 -> 후보` 값과 행동 변화를 동시에 보여준다.
- 잠긴 설계도는 획득 장소 힌트를 보여주되 장착 버튼처럼 보이지 않는다.
- 다음 스테이지의 적/위험 정보는 `원거리 적`, `중장갑`, `독성 지형`처럼 검증된
  압박 태그만 표시한다. 특정 장비를 정답이라고 강요하지 않는다.
- 장비 변경이 실제 저장에 반영되기 전 `준비 완료`에서 전체 구성을 검증한다.
- 한 화면 안에 카드 안의 카드를 만들지 않는다. 왼쪽 종류 목록, 가운데 장비
  목록, 오른쪽 비교/행동 영역의 세 열을 기본으로 한다.

### 대장간

상단 탭은 `제작`, `재제작`, `수리`, `보급` 네 개다. 탭은 동일한 선택 장비를
유지하고 각 작업에 필요한 정보만 바꾼다.

제작/재제작 상세:

- 설계도 실루엣과 전투 역할;
- 현재 재료 등급과 결과 등급;
- 도달 범위, 속도, 대응 방식, 고유 규칙;
- 기본 설계도 값, 재료 기여, 최종 값;
- 보유/필요 재료를 `5 / 3`처럼 혼동하지 않고 `보유 5 · 필요 3`으로 표기;
- 제작 후 남는 수량;
- 장착 중인 장비와 달라지는 값;
- 확정 성공임을 전제로 한 하나의 `제작` 또는 `재제작` 명령.

수리 상세:

- 근접 무기와 방패 상태를 큰 수치와 막대로 표시;
- 무료 최소 정비가 적용되는 이유와 결과;
- 재료 1개당 복구량;
- 선택 수리와 모두 수리;
- 상태 0에서도 `파괴됨`이 아니라 `마모됨`이라고 표시.

보급 상세:

- 현재 화살/최대 화살;
- 기본 무료 보급 결과;
- 표준 화살 8발 제작 비용;
- 별도 원소 화살이나 탄약 종류 선택은 표시하지 않는다.

### 스테이지 지도와 재도전

각 스테이지 항목은 다음을 구분한다.

- 진행 상태: 잠김, 첫 도전, 완료, 재도전 가능;
- 첫 완료 보상;
- 반복 시 최소 보장 재료와 주요 재료 계열;
- 놓친 고정 설계도, NPC 의뢰, 정령 시련;
- 마지막 체크포인트 저장 여부;
- 예상 플레이 시간과 주요 위험 태그.

확률 퍼센트만 나열하지 않는다. `금속 재료 최소 3`, `소형 방패 설계도 미획득`
처럼 결정에 필요한 결과를 보여준다. 기본 수리나 화살이 부족하다는 이유로
스테이지 버튼을 비활성화하지 않는다. 준비 화면으로 안내하고 안전장치를 적용한다.

## Gameplay HUD

### 기본 배치

| 위치 | 내용 | 표시 원칙 |
| --- | --- | --- |
| 좌상단 | 체력, 현재 소비 아이템 횟수 | 항상 표시, 작은 상태 설명 금지 |
| 상단 중앙 | 스테이지 목표/변경 | 변경 시 펼쳐지고 2-3초 뒤 한 줄로 축소 |
| 우상단 | 코인, 일시적 저장 상태 | 재료 전체 수량은 표시하지 않음 |
| 하단 중앙 | 공격, 방어, Q/R/V 기술, 소비 아이템 | 아이콘 + 현재 입력 + 재사용 상태 |
| 하단 좌측 | 화살 수, 근접 무기 상태, 방패 상태 | 얇은 자원 묶음; 30% 이하만 강조 |
| 보스전 상단 | 보스 이름, 체력, 단계 | 일반 목표를 대체, 패턴 설명문 금지 |

HUD는 배경을 넓게 덮는 패널 대신 아이콘, 얇은 막대, 짧은 배경 면을 사용한다.
게임 화면 중앙과 캐릭터 주변을 가리지 않는다.

### 상황 공격 미리보기

- 근접 공격이 선택되면 대상 가장자리에 작은 검 실루엣과 실제 공격 범위의 짧은
  시작 표시를 보여준다.
- 원거리 공격이 선택되면 대상에 활 실루엣과 시야선 끝점을 보여준다.
- 경계 거리에서 장비가 바뀔 때 아이콘은 100-150ms 안에 교차 전환하며 깜빡이지 않는다.
- 화살이 없으면 활 실루엣은 나타나지 않고 하단 화살 아이콘이 한 번만 흔들린다.
- 표적이 없으면 캐릭터 앞에 근접 공격의 방향만 보여준다.
- 범위 시각화와 실제 `Hitbox`/투사체 판정은 같은 데이터에서 만들어져야 한다.

### 방어 피드백

- 방패를 들면 캐릭터 앞 방어 각도와 하단 방패 상태가 함께 반응한다.
- 정밀 방어 구간은 짧은 테두리 수축과 소리로 표시한다.
- 방어 가능한 공격은 일반 경고, 강한 공격은 더 굵은 경고, 방어 불가 공격은
  모양이 끊어진 붉은 파열 표식으로 구분한다.
- 색을 보지 못해도 선 모양, 소리, 동작으로 세 종류를 구분할 수 있어야 한다.

### 기술과 정령석

- `Q`는 근접 무기 실루엣, `R`은 활 실루엣, `V`는 장착 정령석 문양을 사용한다.
- 재사용 대기시간은 숫자와 원형/막대 진행을 함께 제공한다.
- 사용 불가 이유는 가장 가까운 원인 하나만 보여준다: `화살 2발 필요`,
  `재사용 대기 중`, `공중에서 사용할 수 없음`.
- 영문 내부 ID나 긴 기술 설명은 HUD에 표시하지 않는다.

| 설계도 | 펼쳐진 도면 | `E` 확인 | 전체 보상 창, 새 행동과 제작 재료 표시 |
| 정령석 | 고유 문양의 큰 석재 | `E` 확인 | 이름, 세 동조 효과, 시련 상태 표시 |

일반 아이템 수령은 플레이를 멈추지 않는다. 설계도, 정령석, 보스 보상만 전투가
끝난 안전 상태에서 큰 보상 창을 사용한다.

### 수령 문구

- 일반 재료: `강철 조각 +2`처럼 한 줄, 1.5초 이내.
- 여러 재료: 같은 계열은 합치고 최대 세 줄. 넘으면 `외 2종`으로 축약하고
  결과 화면에서 전체를 보여준다.
- 설계도: 이름, 역할, 고유 규칙, 제작 가능 여부.
- 상자: 상자 열림 자체가 아니라 실제 획득 결과를 제목으로 사용.
- 중복 또는 이미 정산된 보상은 조용히 사라지지 않고 저장 복구 상황에만
  `이미 획득한 보상` 한 줄을 제공한다.

## Choice And Result Screens

- 레벨/카드 선택은 현재 장비에 작동하는 선택지만 제공한다.
- 각 선택은 행동 변화 한 줄, 영향받는 장비 아이콘, 현재 값과 결과 값을 보여준다.
- 선택 전에는 적용하지 않고, 확정 후 새 스냅샷을 받은 다음 전투를 재개한다.
- 사망/완료 결과는 원인, 스테이지 진행, 얻은 설계도·정령석·재료, 장비 상태,
  저장 결과를 보여준다.
- 사망 화면은 `다시 시작`과 `대장간/준비`의 차이를 설명하지 않고 결과로
  구분한다. 중단 저장을 소비하는 행동은 별도 확인을 요구한다.

## Input, Focus, And Accessibility

- 모든 명령은 키보드와 표준 게임패드로 완료 가능해야 한다.
- 입력 아이콘은 마지막 사용 장치가 바뀌면 즉시 교체한다.
- 리매핑 시 충돌, 취소, 기본값 복원, 저장 실패 상태를 제공한다.
- 패드 포커스는 화면 진입 시 가장 안전한 주요 선택에 위치하고, 닫은 뒤 원래
  버튼으로 돌아간다.
- 포커스가 없는 버튼, 보이지 않는 스크롤 위치, 포커스 함정이 없어야 한다.
- 조작 대상은 최소 40px, 주요 확인은 44px 이상을 목표로 한다.
- 화면 흔들림, 피해 번쩍임, 정령 효과 강도, 자막/효과음 표시, 진동을 조절한다.
- 위험, 재료, 정령은 색 외에 형태와 문양으로 구분한다.
- 모션 감소 시 튐·자석 이동·패널 전환을 짧은 페이드로 대체한다.

## Responsive And State Matrix

검증 화면 크기:

- `960x540`: 최소 지원, 장비 준비는 2열 또는 탭식으로 재배치;
- `1280x720`: 기본 플레이·준비 기준;
- `1920x1080`: 화면 가장자리에 과도하게 벌어지지 않도록 최대 폭 제한.

모든 화면이 갖춰야 할 상태:

| 상태 | 요구사항 |
| --- | --- |
| 기본 | 주요 행동과 현재 선택이 즉시 보임. |
| 포커스/호버 | 배경색만이 아니라 테두리·실루엣 변화 제공. |
| 선택됨 | 현재 장착/선택과 단순 포커스를 구분. |
| 비활성 | 이유를 한 줄로 제공하며 활성 버튼처럼 보이지 않음. |
| 로딩/저장 중 | 중복 입력 차단, 기존 유효 상태 유지. |
| 빈 상태 | 무엇이 비었고 다음 가능한 행동이 무엇인지 표시. |
| 오류 | 플레이어가 고칠 수 있는 행동과 안전한 돌아가기 제공. |
| 성공 | 새 스냅샷의 실제 결과를 보여준 뒤 입력 해제. |

텍스트는 어떤 지원 크기에서도 컨테이너 밖으로 잘리거나 다음 요소를 덮지 않는다.
한국어 이름과 재료 수량의 최장 예시로 검증한다.
